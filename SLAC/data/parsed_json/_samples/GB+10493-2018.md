## unit17  type=paragraph  level=2  parent=16  prefix=5.1

5.1　道口信号设备分为以下四类：
ａ)　道口自动通知设备；
ｂ)　道口自动通知及人工控制道口信号设备；
ｃ)　道口自动通知及道口自动信号设备；
ｄ)　道口自动通知及道口自动信号、自动栏木设备.
```

## unit19  type=paragraph  level=2  parent=16  prefix=5.3
```
5.3　道口信号应保证任何方向列车接近道口时，自动通知道口看守员或向道路方向报警，报警应符合
ａ)　采用道口自动通知设备时，应向道口看守员报警；
ｂ)　采用道口自动通知及人工控制道口信号设备时，应向道路方向报警；
ｃ)　采用道口自动通知及道口自动信号设备时，应向道路方向及道口看守员报警；
ｄ)　采用道口自动通知及道口自动信号、自动栏木设备时，应向道路方向及道口看守员报警；
ｅ)　报警方式采用音响和灯光信号时，室内应设音响切断设备.
```

3　术语和定义
下列术语和定义适用于本文件.
3.1铁路道口　狉犪犻犾狑犪狔犾犲狏犲犾犮狉狅狊狊犻狀犵铁路线路上铺面宽度在2.5ｍ及以上，直接与道路贯通的平面交叉.
3.2站内咽喉区道口　狊狋犪狋犻狅狀狋犺狉狅犪狋犾犲狏犲犾犮狉狅狊狊犻狀犵位于出站信号机与进站信号机之间的铁路道口.
3.3站内到发线道口　狊狋犪狋犻狅狀狉犲犮犲犻狏犻狀犵犱犲狆犪狉狋狌狉犲狋狉犪犮犽犾犲狏犲犾犮狉狅狊狊犻狀犵跨越全部或部分到发线的铁路道口.
3.4邻近车站的区间道口　狑犪狔狊犻犱犲犾犲狏犲犾犮狉狅狊狊犻狀犵犪犱犼犪犮犲狀狋狋狅狊狋犪狋犻狅狀犌犅10493-2018位于进站信号机外方，从进站信号机(或站界标)至道口距离小于所需接近区段长度的铁路道口.
3.5道口信号　犮狉狅狊狊犻狀犵狊犻犵狀犪犾铁路道口处设置的信号及防护设备的总称.
3.6道口自动通知　犪狌狋狅犿犪狋犻犮犾犲狏犲犾犮狉狅狊狊犻狀犵狑犪狉狀犻狀犵列车接近铁路道口时，自动通知道口看守员.
3.7道口自动信号　犪狌狋狅犿犪狋犻犮犾犲狏犲犾犮狉狅狊狊犻狀犵狊犻犵狀犪犾当列车接近或离去铁路道口时，自动地向道路方向显示禁止或准许通行的信号.
3.8道口信号机　犾犲狏犲犾犮狉狅狊狊犻狀犵狊犻犵狀犪犾面向道路，指示道路车辆、行人禁止或准许通行的装置.
3.9道口遮断信号机　犾犲狏犲犾犮狉狅狊狊犻狀犵犿狅狀狅犻狀犱犻犮犪狋犻狅狀狅犫狊狋狉狌犮狋犻狅狀狊犻犵狀犪犾向列车显示禁止通行的装置.
3.10人工控制道口信号　犿犪狀狌犪犾狅狆犲狉犪狋犲犱犾犲狏犲犾犮狉狅狊狊犻狀犵狊犻犵狀犪犾当列车接近铁路道口时，自动通知道口看守员，并由看守员控制道口信号机的显示.
3.11自动栏木　犪狌狋狅犿犪狋犻犮狅狆犲狉犪狋犲犱犫犪狉狉犻犲狉根据列车接近和离去道口的信息，自动动作的道口栏木.
3.12列车接近通知时间　狑犪狉狀犻狀犵狋犻犿犲狅犳狋犺犲犪狆狆狉狅犪犮犺狅犳狋狉犪犻狀认时间、根据道口实际运用情况适当增加的时间之和.
3.13接近区段长度　犾犲狀犵狋犺狅犳犪狆狆狉狅犪犮犺狊犲犮狋犻狅狀列车接近通知时间内走行长度、道口中心到遮断信号机的长度、列车紧急制动长度之和.
```

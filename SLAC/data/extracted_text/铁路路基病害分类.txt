排水 不 良 分 为 排水 设施 不 良 .排水 设施 不 足 或 外 部 环境 既 有 改变 排水 系统 。
3. 13.1 排水 设施 不 良
排水 设施 不 良 是 指 排水 设施 虽 有 具备 ,但 遭 到 不 同 程度 的 破坏 ,如 阻塞 、 铺 砌 被 破坏 PY UK SB a SF
等 ,不 能 正常 发 挥 排水 作用 。
3. 13.2 排水 设施 不 足
排水 设施 不 足 是 指 路 基 应 有 的 排水 设施 没有 设置 或 不 完备 ,满足 不 了 排水 要 求 。
3.13.3 外 部 环境 变化 影响 取 有 排水 系统
指 由 于 外 部 环境 的 变化 ,引起 排水 通道 的 阻 断 等 。
3.14 危 岩 与 崩塌 落石
3.14.1 危 兰
危 岩 指 在 外 界 因 素 ( 降 水 .强风 ,振动 等 ) 影 响 下 ,山坡 及 路 和 玛 边 坡 上 可 能 失 稳 而 威胁 行车 安全 的 孤
石 或 岩石 块 体 , 多 指数 量 不 多 而 体积 较 大 的 岩 块 。
3. 14.2 ”崩塌 落石
在 地 势 陡峭 .地质 条 件 复杂 的 山坡 上 , 因 长 期 受 风化 侵蚀 或 地 震 及 其 他 外 力 的 影响 , 岩 体 或 土 体 突
然 脱 离 母 体 ,在 自重 作用 下 ,发 生 急剧 地 向 下 倾倒 . 骨 落 .翻滚 和 跳跃 等 现象 称 为 崩塌 。 落 石 指 个 别 岩
块 从 悬崖 陡坡 上 突然 坠落 的 现象 。
3.15 风化 剥落
风化 剥落 指 风 化 的 石 质 或 老 黄土 路 么 边 坡 ,在 风化 及 外 力 因 素 影 响 下 ,成 片 或 块 体 剥 落 ,从 而 危及
行车 安全 。
风化 剥落 多 指 因 地 形 .地 质 原因 而 造成 的 体积 较 小 而 数量 较 多 的 风化 岩石 剥落 。
3. 16 ”膨胀 隆起 (膨胀 岩 或 膨胀 土 )
由 于 路 基本 体内 或 基底 存在 膨胀 土 (膨胀 岩 ) ,在 外 界 水 分 作用 下 路 基 发 生 上 拱 的 现象 。
主要 有 以 下 几 种 特征 :
a) 多 发 生 在 采用 膨胀 土 (膨胀 肉 ) 填 筑 路 基 或 基底 存在 膨胀 土 (膨胀 岩 ) 地 段 ;
b) 党 伴随 着 地 下 水 上 升 或 地 表 水 的 入 渗 。
3.17 ”风蚀 路 基
风蚀 路 基 指 位 于 大 风 区 的 铁路 路 堤 受 风 力 的 作用 ,路 肩 和 路 面 被 吹 蚀 ,使 轨 枕 头 外 露 ,轨道 不 稳
定 。 加 重 巡 道 及 养路 作业 的 困难 ,严重 时 可 威胁 行车 安全 甚至 造成 行车 事故 。 风 蚀 路 基 区 段 与 铁路 沿
线 大 风 的 分 布地 区 一 致 。

## 结论边界与下一步

该比较保留 Direct + b0 作为强而简单的后续基线，停止把当前结果表述为编辑式参数化优于直接分类。相同 context 初值、训练顺序与近似参数数（592,898 / 595,756）不能消除目标、head 初始化、候选 softmax 和全局 DP 等差异；也没有无 b0 的配对控制，不能单独归因于 b0。

24 个样本都来自祖先 train，该 legacy-dev 已曝光，弱参考语义与 family 独立性未获认证。历史保存代码提供索引关联，当前缓存摘要只能冻结本轮数据，不能认证历史 BGE 输出或排除同形状行曾被置换。三 seed、八个 dev 文档不支持显著性、独立泛化、论文新颖性或 RAG 收益结论。

本次六个运行到此结束。下一步仅对已保存的八个 dev 文档做零模型、零 API 的边界变化分解：区分保留 b0、纠正相对弱参考的 b0 差错与引入相对弱参考的新差错，同时保留逐文档 F1，检查终点差来自哪些动作。该事后解释不改变主比较、标签、模型或预算，也不会据此在同批样本上调参。

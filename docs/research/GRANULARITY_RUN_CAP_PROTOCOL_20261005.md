## 固定干预

三种表示均比较两个政策：最多三个输出来源区间（`cap3`），以及不限制来源区间数（`no_cap`）。两者均保留相同的完整 evidence block 1,024 BGE proxy-token 上限。对完整单元、child-max 父单元、atom 三臂都实施干预，避免只放宽细块约束后与受限父单元比较。

除此以外，保持原 query/passage、原 JEV yes 报分、全部候选/no-filter、Dense 与来源位置同分规则、单次贪心扫描、不回访拒绝项、仅合并相邻已选原文区间及完整来源渲染不变。不做 k 网格搜索、不调阈值、不改变报分、不跨空隙补文本。

先完整重放 `cap3` 的六包，与原 chosen、runs、trace、完整渲染及保存 token 数逐字段比较。任一不一致即停止，不报告新的干预结果。新 `no_cap` 仍逐项计算完整拟选包，不假定分词可加或随来源增长单调，也不把旧 skip_runs 的未测 token 当成零。

这项干预仅解释当前贪心选择流程对硬上限的敏感性；它不是满足原三段要求的新算法，也不能证明无段数限制更适合实际生成系统。

## 冻结和评价

两题 × 三种表示 × 两种政策，共十二个包全部生成并封印，再打开同一四份参考区间。保留全部 24 条 annotation×表示×政策的字符覆盖、完整参考覆盖、来源长度、实际输出区间数及完整 proxy tokens。分别比较每种表示的 cap3→no_cap，以及各政策内部的 A/B、B/C；不把不同政策的结果混为公平方法比较。

问题、分数和参考已曝光，这是一项事后诊断，不是独立确认。第一题的两份参考相同；第二题各份范围差异及池外缺失不变。不生成答案，不计算原段落 Evidence F1 或 Answer F1，也不因某一读数改善追加模型调用。

## 另行检查末态几何可行性

对原细块臂全部 70 个 skip_runs 候选，每次独立尝试加入原最终选包，只计算精确原文区间合并后的段数。不累计加入，不改变已保存的包，不读取参考选择候选，也不使用 token 预算。

若某项在最终状态下只需三段或更少，只能说明其几何拒绝条件可能已经消失，不能认定完整渲染可装入预算；若仍需四段，也不能证明多项联合加入或换出候选不可能可行。本检查不实施循环回访或新选择策略。

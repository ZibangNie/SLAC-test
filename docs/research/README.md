**2026-10-04 最新零 API 诊断：事实消失与回答相关损失须分开。** [已有六例的范围检查](NATURAL_LOSS_SCOPE_DIAGNOSIS_20261004.md)发现五例的选定事实确实消失，一例仍由其他段落支持；主体、用途和问题范围决定这些事实是否构成相关损失。两份事后清单共 39 次原文引用核对；没有重标旧参考。有限见证不能证明整包无损，代入 unknown 仍救不回唯一共同有益交换，因此不增加这种门控。三对同证据问题草案中两对适合作狭窄诊断假设，一对因缩写解释混杂保留待改；尚无新 API 执行计划、模型结果或答案收益。

**2026-10-04 最新自然 JEV 探测：损失判断会挡住共同有益交换。** [固定六请求结果](NATURAL_EXCHANGE_JEV_RESULTS_20261004.md)：15 个共同确定维度中新增信息 4/4、损失 2/5、冲突 6/6 与两份原文评审一致；其余 1 个共同 unknown、2 个分歧单独保留。模型识别了两个正向参考，却额外判断三例有损失，拒绝唯一共同有益交换；完整规则只接受了一个范围未定的例子。费用 $0.000425250、未知费用 0、无重试，探测已关闭。未证明自然选择或答案收益；接下来只基于已有材料离线区分事实损失与回答相关损失，不扩大调用。

**2026-10-04 最新自然交换检查：预算可行不等于语义有益。** [固定六例结果](NATURAL_EXCHANGE_SAMPLE_RESULTS_20261004.md)复用缓存 BGE 排名，每题只用第 4 名替换第 3 名，六例均满足旧 k=3／1,024-token 预算。两份分别保存的 AI 原文判断共同支持 1 例部分信息改善；两个候选只有章节标题，另两例的问题范围仍有歧义，分歧保留。独立复核 12 个整包计数及 97 处引用跨度，四项定向测试通过。本轮新增 API、训练和本地模型推理均为 0；未测量答案收益，而且这些自然例子尚未显示损失判断相对 gain-only 的额外换包作用。

**2026-10-04 最新小探测：损失判断改变了替换决定，但新增判断仍有错误。** [固定六请求结果](EXCHANGE_JEV_PROBE_RESULTS_20261004.md)：完整规则接受两个预期有益交换、拒绝四个预期不应接受的交换；同一模型输出的 gain-only 消融误接其中三个。18 个维度中 17 个符合预期，删除唯一编码映射的 X06 仍被判断为有新增信息，但独立的损失判断阻止了换入。费用 $0.000293706，未知费用 0、无重试，本探测已关闭。仅支持这些人工例子上的有限能力，未证明自然 RAG 收益或创新性；接下来先离线检查小型自然样本。

**2026-10-04 最新方法审查：固定预算替换已有直接先例。** [文献与交换判断记录](EVIDENCE_EXCHANGE_GATE_20261004.md)核对 SEAL-RAG、Context-Picker 与 ETS，收窄创新主张。新离线契约分别判断完整新旧包的新增信息、原信息损失和新包内部冲突，只接受有增无损且无冲突的交换。三个人工事实原子的 512 种组合说明：只看候选增益会接受 42 种有损交换，错误地相对保留包判断增益则会接受 91 种无净增益交换；这是精确集合运算，不是 JEV 或 RAG 效果。本阶段新增 API、模型推理和自然数据读取均为 0。

**2026-10-04 最新自然问题检查：定义缺口不等于回答需求。** [固定 6 题的离线诊断](NATURAL_DEFINITION_OPPORTUNITY_20261004.md)完成本地 BGE 的 96 对重排，新增 API 为 0。Dense/BGE 分别有 2/4 次定义目标缺失，均可通过单段替换满足原预算，但追加第四段均违反 k=3；源文复核未建立这些问题必须补入缩写解释，替换反而可能挤掉相关内容。96 对绑定、12 个包及 51 项整包 token 计数经独立复算。暂不因这些结构缺口启动 JEV 实验，下一步先识别查询真正需要的信息。

**2026-10-04 最新离线进展：原文显式定义链接可构建。** [三篇固定开发文档的抽样结果](NATIVE_DEFINITION_FEASIBILITY_20261004.md)：193 个原文字段、151 个段落中，保守规则产生 84 次提及连接，折叠为 48 组单元/缩写连接、44 组单元对；46 组单元/缩写连接跨越非相邻单元。双方原文跨度与完整文本 hash 均绑定，重复定义弃权；12 组未执行的同文本对照通过复核，105 项相关测试通过。本轮 API 为 0。这证明了受限关系的可构建性，未证明语义必要性、JEV/RAG 收益或创新性；下一步检查小样本自然问题证据包中的实际缺口。

**2026-10-04 更新：完成受限六请求语义探测。** [条件 JEV 真实调用结果](CONDITIONAL_JEV_PROBE_RESULTS_20261004.md)：两个固定人工样例对均在事实缺失时判新增、已有同义信息时判无新增，4/4预期符合，服务方报告总费用$0.000160398，未知费用0、无重试。独立核验通过；仅支持这两个例子上的条件区分，不代表结构收益、真实RAG提升或创新性。本次付费探测已结束，下一步先做原文关系可追溯性及对照的离线设计。

研究脚本和测试以LF字节保存；公开JSON/SVG使用`.gitattributes`的`-text`保留各自封印字节，避免Windows/Git换行转换改变hash。早期部分生成文件是CRLF，不能只因数值相同就当成同一字节来源；[公开字节核对](PUBLIC_RESULT_BYTES_20260927.md)记录了此次修正。已有生产模块的换行及旧封印没有改写；迁移旧artifact时仍应保留绑定的原始字节与路径映射。

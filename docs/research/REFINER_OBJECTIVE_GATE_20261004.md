# Refiner 的动作监督与最终边界目标

2026-10-04。**当前编辑监督、最佳动作路径和最终边界概率是不同对象；旧普通分类器也未满足同 `b0` 信息的比较要求。** 两个手工例子的40种组合用精确分数核对了这些区别。新增 API、自然样本读取、神经运行时、模型推理和训练均为0。

本轮只调用真实的标准库标签契约，不执行 tensor decoder 或 projector。例子是为说明区别而构造的，不能当作自然错误率、模型失败或新目标的质量优势。[可复现脚本](probe_refiner_objective.py)与[完整结果](results/refiner_objective_20261004.json)保留全部组合，包括非法及零质量项。

## 现有监督与基线的问题

[`label_contract.py`](../../SLAC/refiner/slac_refiner/label_contract.py) 对给定 `b0` 和最终边界选出一个最低编辑成本的 canonical 分解。最低成本标签确定，并不意味着只有一条合法动作路径。一个 gap 的 `b0=[1]`、目标 `[1]` 同时允许 KEEP+无插入和 DEL+插回原 gap；前者成本0，后者成本2，canonical 选前者。

[`RefinerLoss`](../../SLAC/refiner/slac_refiner/models/losses.py) 使用单一 edit class 的交叉熵及 residual INSERT 的 BCE，分别按有效 edit/gap 数求均值，再加权并可加入成本正则。它既不对同一最终边界的多条分解求和，也没有对全部合法分解重新归一化。这是当前明确的训练选择，不是由反例即可断言的实现错误。

[`RefinerHeads`](../../SLAC/refiner/slac_refiner/models/heads.py) 的 insert 分支只读取相邻 atom 的上下文表示；`g0_positions` 进入 pointer 与 delete 分支。旧 [`run_foundation_probe.py`](../../SLAC/refiner/scripts/run_foundation_probe.py) 的直接分类模式仅用 insert logits 训练和预测，因此其输出不以 `b0` 为条件。虽然保存结构相同，query/key/delete 参数不在直接分类损失的依赖路径上：

| hidden128 微诊断 | 保存参数 | 与该目标有依赖关系的参数 |
|---|---:|---:|
| 编辑式 Refiner | 592,898 | 592,898 |
| 旧直接分类分支 | 592,898 | 395,777 |

差额197,121来自两个 pointer projection及delete head。这里是源码与形状的静态依赖计数，排除冻结BGE；没有测量某批数据的实际梯度非零数。旧分数仍有开发诊断价值，但不能满足[既定公平对照](EXPERIMENT_PROTOCOL_DRAFT.md)中的同输入信息要求，保存参数相同也不足以认证有效容量相同。

## 一个明确的新分布定义

为避免把独立 OR 公式误当现有模型概率，本轮仅定义一个解析对照。给定每个 seed 的 edit 概率及每个 gap 的插入概率，先取这些因子的乘积 `q(a,I)`，再限制到真实标签契约允许的分解：编辑输出严格单调、不重复，INSERT 不与编辑输出重叠。允许非 canonical 分解。

令合法集合为 `L`、回放函数为 `R`，则：

`Z = sum_{(a,I) in L} q(a,I)`

`P(Y=b | L) = sum_{(a,I) in L, R(a,I)=b} q(a,I) / Z`

该分布没有 projector 或编辑成本惩罚；它是本轮显式定义的分析对象，**不是当前训练损失或分步 decoder 的已校准输出概率**。要求只保留 canonical 分解会改变 `L`，不能继续沿用下面的数值。

## 两个精确例子

第一例仅一gap、K=0：KEEP概率2/5、DEL概率3/5、INSERT概率2/5。

| 动作及插入位 | 原始质量 | 合法 | 最终边界 |
|---|---:|---|---|
| KEEP，0 | 6/25 | 是 | 1 |
| KEEP，1 | 4/25 | 否：重复插入 | — |
| DEL，0 | 9/25 | 是 | 0 |
| DEL，1 | 6/25 | 是 | 1 |

`Z=21/25`。最大合法单路径给出0；按最终边界汇总后，1的条件概率为4/7、0为3/7。忽略合法性、允许冗余事件的独立 OR 则给出16/25，而非4/7；两者采用了不同分布定义。

按源码推导，foundation 的**零编辑代价、0.5插入阈值、投影前**路径会给出0。但生产默认删除惩罚1使 `log(.4) > log(.6)-1`，会选择KEEP，给出1。因此本例不能写成“当前生产模型错、边缘化修复了它”；本轮也没有实际调用decoder来测量该行为。

第二例有两个gap和两个seed、K=1，每个seed的DEL及两个可达目标各占1/3，插入概率均为0。36个配置中，正质量的合法路径6条、非法路径3条，其余27个是零质量的插入变体，合法总质量2/3。合法条件化后两个gap的边缘概率均为1/2，独立OR均为5/9。交叉路径 `SHIFT:+1 / SHIFT:-1` 虽然集合union仍为 `[1,1]`，但严格回放正确拒绝；不能只按最后的集合去重就把非法路径纳入求和。

40种组合只来自这两个固定手工例子，不是数据集扫描。脚本的精确断言全部通过，独立枚举复核了概率与合法集合；没有按结果调整参数或扩大案例。

## 研究价值与下一步

对映射到同一输出的路径求和不是新思想。[Ristad与Yianilos的随机编辑距离](https://arxiv.org/pdf/cmp-lg/9610005)已把字符串对概率定义为对应编辑路径的总和；[CTC](https://www.cs.toronto.edu/~graves/icml_2006.pdf)也区分路径概率与输出标签概率，并用动态规划求和。[Makarov与Clematide 2018](https://aclanthology.org/D18-1314/)直接讨论了编辑动作存在多个有效分解时，依赖单一金动作序列的局限。这些先例不证明哪种目标更适合SLAC，也不证明边缘化会提高RAG质量。

因此，本轮**不把独立OR接入训练，不因手工反例重训，不宣称新的边缘化算法贡献**。等价类目标若继续研究，须处理合法性、归一化、可计算性和真实质量；它仍是编辑式参数化，不能自动充当以`b0`为条件的直接分类基线。

下一项具体实现应先补足这个基线：双方接收同一文本表示和明确的`b0`状态，报告实际损失依赖参数及上下文范围，保留同一预算和后处理。先用小型张量检查输入依赖、mask及有效梯度路径，旧微诊断与旧权重保持可复现；这些检查通过后仍需独立审查训练参考和样本范围，不能将合成检查冒充质量结论。研究目标继续，旧900题付费计划保持暂停。

# Refiner 原文坐标与预算文本：固定两文档检查

2026-10-04。本轮新增 API、模型推理、训练、权重、凭据及金标读取均为 0。[聚合结果](results/refiner_source_budget_20261004.json)保留全部分母与来源 SHA256；[来源检查](probe_refiner_source_alignment.py)及[投影／导出检查](probe_refiner_projection_export.py)可复核计算路径。

**79/83 个原生单元可以建立唯一的精确原文对应，另外 4 个不能直接接入现有无损模式；本样本未发现投影后导出超预算。默认投影还独立合并了 27 个原生边界，这部分变化必须与学习到的边界贡献分开。** 这些是接口与对照设计证据，没有新增 JEV、Refiner 或 RAG 质量结果。

## 固定范围与方法

沿用[前一阶段](NATIVE_REFINER_GRANULARITY_RESULTS_20261004.md)已冻结的两篇开发文档、83 个 native Unit、251 个 atom 和相同 `b0`。只读取前阶段的有界输入与人工恒等边界 fixture，没有重新扫描上游语料。方法、输入、五份源码与本地 BGE tokenizer 在自然样本运行前封印；两项探针各运行一次，未按结果改阈值或选样本。

来源映射在每个原生单元内部枚举 atom 的全部精确子串位置，再用动态规划统计所有有序、非重叠的完整映射，计数在 2 处饱和。只为完整映射唯一的单元输出 Python 字符串坐标；不按首次命中猜位置，也不以模糊匹配、空白压缩或 Unicode 规范化制造相等。未命中或多解的单元保留在总分母中。

对唯一映射，调用真实 `projector.spans_to_units` 的 `source_text/atom_char_spans` 模式，分别构造逐 atom 分区和整单元分区，核验两者都能逐字节还原原文。首部、atom 间和尾部的未匹配字符单独计数；这些间隔由原有 projector 保留，不默认为语义无关。这里验证的是单元内重建，没有宣称整篇文档的来源桥接已完成。

[27 项合成测试](../../tests/research/test_refiner_source_alignment.py)通过，其中独立 Cartesian 枚举检验了 7,740 组很短的人工字符串组合，覆盖重复文字、全链唯一／多解、顺序与重叠冲突、非空白间隔、Unicode 字符坐标及禁止规范化匹配。这不是新增自然数据样本。

另以独立子串枚举复核了全部 83 单元的映射分类，并核对已保存的 83 个固定区间、56 个规则投影区间、来源间隔、文本与实际预算；187 种唯一字符串的本地 tokenizer 复算通过。复核没有重跑 builder 或投影决策，也没有扩大数据范围。

## 来源对应结果

| 指标 | 文档 1 | 文档 2 | 合计 |
|---|---:|---:|---:|
| 固定原生单元 | 60 | 23 | 83 |
| 全部 atoms 可唯一、有序对应原文的单元 | 60 | 19 | 79 |
| 缺少完整精确映射的单元 | 0 | 4 | 4 |
| 存在多条完整映射的单元 | 0 | 0 | 0 |
| 唯一单元内的 atoms | 177 | 57 | 234 |
| 缺少完整映射的单元内 atoms | 0 | 17 | 17 |
| 本身在原单元中无精确子串位置的 atom | 0 | 4 | 4 |

**17 是四个失败单元包含的 atom 总数，真正没有单独精确命中的只有 4 个。** 每个失败单元恰有一个此类 atom，其余 13 个有独立命中，但探针没有据此为整个失败单元发放完整坐标。失败单元与前阶段的四项轻量规范化变化一致，不能直接满足现有无损 projector 要求的 `source_text[start:end] == atom`。

79 个唯一单元均通过真实 source-mode 重建，间隔内未匹配的非空白字符数为 0。其中 73 个原文与旧导出文本逐字节一致；另外 6 个保留原文空白后各比旧导出多 1 个实际 BGE token。对应原文／导出 token 对为 `(28,27)、(180,179)、(86,85)、(145,144)、(52,51)、(143,142)`。这说明原文保留方式可能改变计数，不能从“只改空白”直接推断预算相等；六次单元计数的差也不是一个合并证据包的预算差。

## 投影与导出的实际预算

两个层次分别测量，均按完整 span 文本用冻结 BGE tokenizer 计数，包含 special tokens、禁用截断，未相加 atom token 数冒充块长度。

1. **固定边界文本对照：** 同一 `b0` 的 83 个区间，比较真实 projector 的 legacy 换行拼接与前阶段 exporter 的空格拼接。
2. **默认规则投影 fixture：** 同一 `b0` 输入真实 `project_boundary_vector`，使用默认硬上限 64 atoms／1,600 chars／384 tokens，软下限 2／20／48，`strict=True`。没有模型 `gap_scores`，也未传来源坐标。用返回的 `projected_b` 构造明确人工规则候选，再交真实 exporter。此路径未运行预测模型，不等于实际推理候选。

| 测量 | 固定 `b0` | 默认规则投影后 |
|---|---:|---:|
| chunk 总数 | 83（60/23） | 56（41/15） |
| 投影文本与导出文本字节相同 | 30/83 | 0/56 |
| 两种文本经空白规范化后相同 | 83/83 | 56/56 |
| 两种文本实际整块 token 数相同 | 83/83 | 56/56 |
| 投影文本违反任一硬上限 | 0 | 0 |
| 导出文本违反任一硬上限 | 0 | 0 |

默认投影没有触发硬上限拆分；软下限合并分别删除 19/8 个边界，合计 27 个，没有新增边界。最终没有未满足软下限的块，导出块最大长度分别为 274/304 tokens。两种文本的实际字符数也逐块相同。本样本的字节差异没有导致预算违规，不据此声称已证实超限 bug，也不据此保证其他输入或 tokenizer 下均相等。

固定 `b0` 与规则投影结果是同一输入的两层机械对照，不是两种预测模型。`gap_scores=None` 下的合并决定也不能替代带模型分数的真实推理。exporter 仍硬编码 `refiner_epoch8` 来源字符串，私有产物外层显式标记 `rule_projection_fixture` 和 `model_inference=false`，避免把该字符串当成学习预测的证明。

## 对框架接入和研究比较的影响

当前原文坐标接线不能直接全通过。后续若要保留原生证据，需要在文本转换发生时记录对应关系，明确区分模型看到的规范化文本与实际渲染的原文；不能在事后给规范化 atom 强行贴上“精确原文切片”的标签，也不能因部分匹配就算作完整参考段落命中。

公平的学习边界比较至少需要区分原 `b0`、同样规则投影后的 `b0`、以及同样投影设置下的模型边界。否则默认软合并自己造成的 27 个边界变化，可能被错误归因于 Refiner。这个要求来自本次实测，不代表规则或模型的语义效果已知。

下一步保持零 API：为 builder 的文本转换设计最小的双文本来源契约，先用合成反例验证原文覆盖与坐标，再决定如何接入现有 projector/exporter。暂不为当前样本未出现的预算违规增添修复，不扩大样本或启动模型实验。仍需后续真实预测、独立判断与公平质量对照，才能检验 SLAC×JEV 的研究贡献。

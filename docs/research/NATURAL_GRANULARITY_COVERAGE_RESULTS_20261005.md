# 固定两题的粒度与参考覆盖结果

2026-10-05。按[执行前协议](NATURAL_GRANULARITY_COVERAGE_PROTOCOL_20261005.md)只复用已有两题、两篇来源文档及全部四份 annotation，不扩样、不调用模型或 API。**原始 b0 与规则投影均有 3/4 份 annotation 存在满足最多三块、完整证据块不超过 1,024 BGE proxy tokens 的覆盖见证；逐 atom 分块为 2/4。** 第一题的两份 annotation 具有相同参考区间，不能把四份 annotation 当作四个独立问题，也不能把这些比例当作总体准确率。

这是已知参考时对分区表示能力的检查，使用固定文档的全部块。它不是实际检索或选包效果、语义充分性、Evidence F1、Answer F1、JEV 增益或学习到的 Refiner 效果。尤其是，完整覆盖一份标注不是已证明的回答必要条件。

## 全部固定结果

各分区保留同一来源文档的全部原文字符。第一篇共 22,993 字符，第二篇 10,116 字符；原始 b0 分别为 60/23 块，规则投影为 41/15 块，逐 atom 为 177/74 块。字符长度按 Python Unicode 字符计，不是 PDF 字节。

四份 annotation 全部精确映射到唯一的 native Unit，无模糊匹配、未匹配、多位置匹配、不可回答或空参考。11 条原参考条目逐条保留；同一 annotation 内区间取并集，不跨 annotation 合并。

总计 12 条分区记录，8 条满足数量限制并完成整个 evidence block 的计数，重复完整字符串复用缓存，因此实际编码三个不同字符串。这里的 8 条不是八个独立包：第一题两个 annotation 相同，且两题适用的原始 b0 与规则投影见证均有完全相同的文本与区间。

## 观察及其解释

第一题的三个分区都能完整覆盖相同的 244 个参考字符，必需块原文总量均为 246 字符。逐 atom 变为两块后，完整渲染计数由 180 增至 240；该样本增加的是分块后的表示开销，没有增加所选来源字符。这是在当前最小 metadata 模板和 BGE tokenizer 下的观察，不能推广为固定的每块成本。

第二题第二份 annotation 的原始 b0 与规则投影见证完全相同，都是 971 个来源字符、373 proxy tokens。逐 atom 覆盖相同的来源字符却需要五块，因此在本轮严格的 k=3 口径下不可行。**这给出了一个具体反例：更细切分即使不丢原文，也可能降低固定块数下的完整参考覆盖能力。** 这不是另一次对旧弱标签 F1 的测量，也没有运行学习模型。

第二题第一份 annotation 包含八个参考单元。规则投影把必需块数从八降到六，但仍超过三；必需来源字符由 1,757 增至 2,739。规则合并没有增加本轮的可行 annotation 数，并带入更多非参考字符。这里没有证明这些额外字符有害，也没有断言 token 预算会失败。

这两个问题只支持局部结构诊断，不能据此宣称分区或算法优胜。下面另列事后包装检查，原执行协议、十二条主结果及其 k 定义保持不变。

## 事后检查：相邻来源区间合并

看到主结果后，对全部十二份已保存的必需集合应用同一规则：只合并相互接触的来源区间，不跨越空隙，不增加或删去任何来源字符。此时 k 改为计数输出的连续原文区间，而不是检索块。这是另一种打包政策，不能替换上面的预设比较，也不是再次运行或调优主实验。

| 题序 / annotation | 原始 b0：输出区间 / tokens | 规则投影：输出区间 / tokens | 逐 atom：输出区间 / tokens |
|---|---:|---:|---:|
| 1 / 1 | 1 / 180 | 1 / 180 | 1 / 180 |
| 1 / 2 | 1 / 180 | 1 / 180 | 1 / 180 |
| 2 / 1 | 3 / 674 | 1 / 789 | 3 / 674 |
| 2 / 2 | 1 / 373 | 1 / 373 | 1 / 373 |

**改为输出区间计数后，三种分区全部四份 annotation 都有预算内覆盖见证。** 原始 b0 与逐 atom 在每份 annotation 上合并后的区间及完整渲染逐字相同，原先的差别在这些样本中由包装消除。规则投影在第二题第一份 annotation 上仍带入更多字符，虽然只输出一段，其完整计数 789 仍高于另外两臂的 674；不能只看输出段数推测成本。

主实验已测量的相同完整字符串直接复用计数；仅对两个新字符串执行了本地分词。十二份选择均逐字符验证合并前后集合相同，原参考覆盖仍保留。没有重新选证据、调用 JEV、读取新参考或扩大样本。代码见[事后分析脚本](analyze_coverage_coalescing.py)，完整数值见[单独的公开 JSON](results/coverage_coalescing_posthoc_20261005.json)。

该操作本身不依赖参考，但本轮被操作的集合是参考辅助得到的，因此 4/4 仍不是可部署选择器成绩。它定位了下一步需要解决的实际问题：在不看参考时如何选择证据，而非利用分块数量口径制造收益。后续先在固定已有候选包上检查来源区间合并能否保持选择与来源含义，再考虑是否有值得少量 JEV 调用验证的语义差异。仅做相邻合并不构成论文创新主张。

## 范围与可复核产物

运行只读取预先绑定的两篇完整来源文档、保存的三个分区和按身份匹配的两行参考。没有重跑 atomizer、投影、Refiner、训练或 API，也没有重读上游问答全集。已有六行参考子集的物理行序不同于题序，参考准备阶段按身份选择了第六、第三行，并在解码前固定了身份与协议。

完整 evidence block 使用生产 `render_evidence_block(..., preserve_source_text=True)`。计数包含 BGE special tokens、禁用截断，未相加片段 token。预算不含系统指令、独立 query message、memory、provider framing 或输出；BGE proxy tokens 不是供应商计费 tokens，也不能证明完整模型请求满足上下文限制。无单调 token 成本假设；本次未出现需要判断 supersets 的超 token 预算状态。

数值实现及运行入口：[区间 helper](partition_coverage.py)、[固定探测脚本](probe_natural_partition_coverage.py)。helper 的 57 项测试在自然参考读取前通过，包含 n≤5 的独立逐字符枚举以及抽象的非单调成本反例；这些测试证明实现性质，不是自然模型效果。原文、身份、逐条区间和完整包保存在本地私有产物中；[公开数值及输入绑定](results/natural_granularity_coverage_20261005.json)保留全部 12 条匿名记录。

另一次独立复核不导入区间 helper 或生产 renderer，以字符位置集合检查了主实验全部十二个必需集合、六个完整分区及十一条参考映射，并独立拼接八份适用的完整渲染；字符、字符串及 hash 均一致。token 数沿用原绑定运行的整块计数，没有把字符串复核冒充独立重分词。

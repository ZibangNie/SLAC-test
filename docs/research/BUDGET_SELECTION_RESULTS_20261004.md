## 当前发现

精确优化现有 JEV 分数之和，只改变了 **2/77 题**的选包，75 题保持不变；两题虽然提高了代理目标，Evidence F1 却都下降。全体题等权 Evidence F1 从 **0.391755 降至 0.380933**。这次实验没有显示现有分数和目标的质量收益。预算求解作为框架组件保留，但不提升为默认策略，也不作为新算法创新主张。

两种精确方法都完整枚举给定合法域。常规精确方法的两次效用提升均增加一个证据单元；匹配资源方法保留每题原包的实际 token 上限及单元数上限，仍有两次较小效用提升。分数密度方法节省 tokens，但原始报分效用普遍下降；在质量评分前不作性价比结论。

## 验证与成本

77 题原贪心的选择、包内容哈希和保存 token 数全部复现。缓存实验耗时 **74.797 秒**，共枚举 3,184 个重复兼容子集，新增本地分词 2,604 次；模型 API 请求、答案生成、训练和密钥读取均为 **0**。总量计算是实际实验，不是逐条人工检查数据。

选择器、缓存适配器及证据评价器分别通过 56、13 和 14 项合成测试。独立 bitmask 实现另检查 208 个合成问题及 697 子集的边界案例。真实选择结果 QA 按事先冻结哈希选取 **8 个 family、14 题**；独立验证四方法共 56 个包，直接重新分词 585 次，不继承旧 token 缓存，全部一致。部分 family 只有一题，未补题，也未额外选择改变结果的题目进行数值检查。

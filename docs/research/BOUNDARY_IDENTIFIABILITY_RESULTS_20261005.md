# 固定 atom 与规范输出契约下的边界表示能力

2026-10-05。这里关闭一个具体创新表述：**若允许选择全部基础 atoms，边界只能在这些 atom 端点上编辑，并使用同一规范来源渲染，那么 split／merge 本身不会增加 all-atom 选择能够表达的证据输出。** 它仍可能改变评分、搜索和成本；这些是需要另外验证的作用，不能从边界变化直接推出。

本轮只有数学构造、两个五 atom 合成输入和一个两 atom 反例。没有自然数据读取、API、模型、tokenizer、训练或新的语义标签。这是机制的排除条件，不是新算法、自然效果或论文新颖性结论。

## 明确假设后的构造证明

固定文档原文、问题、atom 的来源坐标和可见候选域。合法块必须严格等于同一连续来源分量中相邻完整 atoms 的坐标并集，不能切入 atom 内部，不能跨不在候选域的缺口补文本。

选中块后，先合并 touching source spans，再按来源排序。稳定 ID、正文以及其余所有模型可见字段必须只由该规范结果和固定问题决定；不允许保留分区序号、不同路径或不同评分等额外变化。所有可行性约束只作用于最终结果，例如最终 run 数 R 和完整 evidence block 的成本 B。没有合并前 item 数限制、评分阈值或搜索过程的中间态限制。

令 F(P) 表示分区 P 下，选择任意完整块子集所能生成的全部可行规范输出。若细分区 Q 细化 P，对 P 的任一可行选集，把每个选中粗块换成它的全部细子块，来源坐标并集保持相同。因此最终 runs、ID、完整字符串和成本完全相同，得到：

`F(P) ⊆ F(Q) ⊆ F(all-atoms)`。

这个构造无需 token 成本可加，也无需“添加文本必然增加 token 数”的假设：比较的是同一最终字符串，而不是分别估计各块再求和。空选集也保留。不同位置的重复正文不能因此混为相同来源覆盖。

**F(all-atoms) 是可行表示集合，不是一种免费获得最佳答案的算法。** 穷举选择可能昂贵，评分也未必可靠；集合包含不保证实际 greedy 输出、运行时间或回答更好。

## 有界实现检查与反例

[事前协议](BOUNDARY_IDENTIFIABILITY_PROTOCOL_20261005.md)固定连续与带缺口两个输入。带缺口例的六个原文字符不属于候选域，所有合法分区必须断开，渲染不得把它们补回来。执行真实 `merge_spans` 和完整 `render_evidence_block`，检查基于块的选择与对应 atom 选择产生完全相同的 runs 和字符串。

| 输入 | 合法分区数 | 完整块选集渲染比较 | 粗／细分区对，含自身 | 加约束后的包含检查 |
|---|---:|---:|---:|---:|
| 连续五 atom | 16 | 162 | 81 | 486 |
| 带缺口五 atom | 8 | 108 | 27 | 162 |
| 合计 | 24 | 270 | 108 | 648 |

全部通过。每例保留 32 个 atom 子集及完整字符串。约束组合为 R∈{1,2}，完整 UTF-8 字节预算 B∈{0,512,4096}，**不是 token 预算**。B=0 时只有空选集；这两个小例子在相同 R 下的 512／4096-byte 可行集合计数相同，不将其包装成紧 token 预算验证。有限检查核验代码和 renderer 的对应关系；一般结论来自上面的构造证明。

反例也成立：source=`ab`，基础 atoms 为 `a`、`b`，粗分区只有 `ab`。若另加 **合并前 item cap=1**，粗分区可以输出 `ab`，细分区最多选一个 atom，不能输出 `ab`。两者最终都可受 run cap=1 约束，但这个 run 约束不能取消 item cap 的区别。因此不能把结论直接推广到按记录数量限制的生产 pack。

[上一阶段](LOCAL_EDIT_VISIBILITY_RESULTS_20261005.md)已验证另一条边界：实际 renderer 会暴露 chunk ID 等字段，仅正文或覆盖相同不保证消息相同。本轮明确统一这些字段，不把这一研究契约描述成默认生产行为。

## 对 SLAC × JEV 下一步的影响

在固定 atom 域内，把“边界编辑产生了 all-atom 无法表达的新证据”作为理由不成立；也不能把不同包装下的高分直接当作 JEV 学到了更好的边界。如果重新检索、扩展候选域或引入 atom 内切点，已经改变了上述问题，需另行声明。

仍可研究的作用只有在被隔离后才有意义：

| 待测作用 | 必须固定或匹配 | 需要的独立证据 |
|---|---|---|
| 评分上下文 | 问题、输出域、可见来源信息、相同预算；加入固定窗口／父段上下文对照 | 上下文评分改正了自然误判，且最终交给回答者的证据支持相应结论，不能只用 JEV 自己的分数认证。 |
| 有限评分成本 | 来源曝光、有效请求输入、缓存、调用与输入成本 | 在相同成本下改善独立效用，或在相同效用下减少成本；完整输出 token 预算不等于评分费用预算。 |
| 有限搜索的分组提案 | 相同评分目标、总搜索额度与约束 | 优于简单分组／回访等控制；只赢单次逐 atom 贪心可能只是绕过不可行的中间状态。 |

这些都不是本轮已验证的增益，也不是已确认文献空白。[已有机制对照](GRANULARITY_PARENT_CONTROL_20261005.md)与[训练目标准入](UTILITY_TRAINED_CHUNKING_GATE_20261005.md)继续适用。此次没有刷新文献，不新增“尚无人研究”的判断。

当前不实现或训练一个仅改分区的 query-aware 模块。下一步只保留**评分上下文是否提供有效、可交付给回答者的信息**这一待测问题：先定义相同来源曝光和固定窗口对照，并从另行限定的小样本中检查是否存在自然失败见证。不得重新调此前两题的选包变体，不因给机制换名字而跳过独立效用要求；在该见证和对照成立前，不追加评分调用。

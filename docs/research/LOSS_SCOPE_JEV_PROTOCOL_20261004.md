## 不改变的判断与唯一一次执行

保持现有 exchange 的三个判断问题、选择 schema、证据独立解释规则和 provider 配置。每个请求仍收集 gain/loss/conflict 三维，以避免同时改变任务格式。gain/conflict 没有为这些改写题标注真值，只作描述性输出；主要读出仅使用 loss。

模型请求仅投影 query、原证据包、候选和交换角色。不发送预期标签、目标 claim ID、正负角色、问题对 ID、另一道问题、评审理由或旧模型结果。记录在本地的配对与预期只用于离线读出。四个请求须有不同绑定，同时逐对核对除 query 外的完整 wire payload 一致。

使用现有 OpenRouter decisions 客户端的冻结端点、`typesafe/jev-1.13`、预期返回模型 `typesafe/jev-1.13-20260917` 及固定 TypeSafe provider。新的四请求准入只收窄计划规模；旧客户端、已关闭计划与三维判断契约不修改。

| 项目 | 固定上限 |
|---|---:|
| 请求数／判断维度 | 4／12 |
| 单请求预留／合计预留 | USD 0.005／0.020 |
| 单请求等待／外层进程期限 | 30 秒／120 秒 |
| S/T 单元数／整包 BGE tokens | 3／1,024 |
| 比较证据库存 BGE tokens | 2,048 |
| 完整 wire／响应体 | 24,000／65,536 bytes |
| 重试、自动重启、提示修订后重跑 | 0 |

预留额度不是已花费用，也不是服务方账户硬上限。客户端逐请求预先登记费用责任；超额或未知费用保留原记录并停止后续请求，不重试。服务方已接受的请求不能靠终止本地进程保证撤销。密钥在本地 worker 完成来源与 wire 验证后才加载，原始数据和凭据不公开。运行输出独占目录，计划执行凭证只能创建一次。

执行前必须完成原文语义复核、定向测试、真实本地 tokenizer 的完整四请求计数、wire 投影检查、代码及本协议推送。外层监督器确认 worker 终止后才读出最终结果。未尝试、错误、缺失、unknown 与已完成结果分别保存，不能删掉失败问题对改变分母。

## 预先固定的读出

主分母始终是 **2 个问题对**。各对按“消失目标／保留目标”的顺序报告 loss：

- **yes/no**：符合该对的窄范围预期，记为成功区分。
- **yes/yes**：未在保留目标上抑制损失判断；与对问题不敏感的表现相容，但不能确定内部机制。
- **no/no**：没有识别消失目标的相关损失。
- **no/yes**：方向相反。
- 任意 **unknown、错误或未观察**：单列，不当成 no，也不从两个固定问题对中删除。

同时报告全部四题的三维标签、完成数、实际费用、未知费用、token 用量、实际模型版本及进程状态。可列出 loss 单题符合数／4 作为辅助描述，但不称准确率：恒答 yes 或 no 都能得到 2/4 单题符合，却不能成功区分任何一对。不得用未标注的 gain/conflict 拼接成整体正确率。

若成功区分 2/2，只支持“现有契约在这两组明确提问间可以改变损失判断”，不能说明旧自然题的争议已经解决。若少于 2/2，保留全部输出，分析失败侧究竟涉及相关性范围、支持丢失还是 unknown；不立即扩大请求或调提示重跑。无论结果如何，下一步回到算法假设与既有材料，而不是自动恢复大规模 API 实验。

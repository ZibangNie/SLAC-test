# 边界改动分解与全部切开控制

2026-10-05。在[固定六次训练](CACHED_BOUNDARY_COMPARISON_RESULTS_20261004.md)之后，仅复用八个 legacy-dev 文档的最终预测做事后数值分析。**Direct seed47 的 487 个 gap 全部预测为边界。无需模型的“每个 atom 单独切开”控制，macro F1 已达 0.869255；三个 Direct seed 中只有 seed29 超过它。** 因此，不能将此前 0.874188 对 0.824085 的模型间终点比较，表述为已建立有意义的边界学习收益。

本轮新增 API、模型推理、训练、tokenizer 调用和数据文档均为 0。分解脚本只读取既有数值向量；不打开上游全量数据或自然文本。

## 冻结向量的改动分解

每个 gap 记初始边界为 b、冻结弱参考为 y、最终预测为 p。四类互斥且完备：保持正确 `p=b=y`，保持差错 `p=b≠y`，纠正差错 `b≠y 且 p=y`，引入差错 `b=y 且 p≠y`。“正确／差错”只指与弱参考是否一致，不判断弱参考本身或语义质量。

保留全部 48 个文档运行记录的 `(b,y,p)` 八格计数、TP/FP/FN、文档 F1 及与 b0 的差。每个 run 都使用相同八篇文档、487 个 gap；初始 b0 为 TP 324、FP 73、FN 44，共 117 个差错。所有使用的 b0 与 final-dev 向量均满足 raw=projected。

三个 Edit run 各有一个文档完全保持 b0，三个 Direct run 均为零。Edit 的最终变化以删除初始边界为主；Direct 会纠正更多相对弱参考的漏边界，也会引入新差错。这只是输出行为，不能据此定位损失、初始化或解码器的因果作用。

逐行校验：旧差错数 = 保持差错 + 纠正差错；新差错数 = 保持差错 + 引入差错；改变数 = 纠正差错 + 引入差错。逐 gap 差错总数不等于逐文档 macro F1：seed47 Direct 纠正 44 项、引入 46 项，总差错从 117 增为 119，但 macro F1 仍从 0.842748 增为 0.869255。该现象不表示错误更少。

## 看到退化后追加的简单控制

原分解未预定比较“全部切开”；发现 seed47 Direct 只新增、未删除 b0 边界之后，追加这个纯数值控制。它是明确的事后合理性检查，不替换原主比较，不作为预注册确认。无需权重或自然文本：对每个文档令所有内部 gap 的预测为 1，F1 为 `2 × gold_positive / (gap_count + gold_positive)`，零分母仍记 0。

八个文档的 gap 数与弱参考正边界数依原顺序为 `(67,51), (81,57), (19,13), (17,17), (89,81), (37,35), (123,84), (54,30)`。总共 487 个 gap 中有 368 个弱参考正边界（75.56%）。逐文档计算后取均值，全部切开的 F1 为 **0.869254631507479**。

## 证据边界与研究决定

分解与原主结果一致，独立审查从原数值向量重算全部 48 行，并独立确认全边界退化和八行控制。没有重跑模型、投影或训练。完整计数、各文档数值、来源及审计摘要见[公开聚合 JSON](results/cached_boundary_changes_20261005.json)，分解方法见[离线脚本](analyze_cached_boundary_changes.py)。公开结果不包含原文、身份或逐 gap 位置向量。

这次检查降低了对边界 F1 的解释强度：该弱参考集合本身偏向密集切分，简单全部切开就能取得接近模型均值的结果。它不能证明数据标注错误，也不能证明所有边界模型无效。八篇已曝光文档与三次重复初始化仍不支持独立泛化、JEV 或回答收益结论。

后续保留全部切开、b0 与 Direct 作为必须面对的简单控制，不继续在这批样本上调参或扩训。下一步零 API 核查这批弱标签和 atom 粒度的生成契约，明确边界目标是否足以约束有用的 chunk；再决定如何检验真实 SLAC×JEV 的粒度与证据选择收益。模型间 F1 领先不作为启动更大付费实验的依据。

# 下游效用监督边界：相关工作与下一项准入检查

2026-10-05。当前需要改进训练目标与实际检索效用的联系，但**将教师换成 JEV 本身不足以区分新方法**。本轮仅查阅原始论文，没有建立训练集、启动训练或调用评分／生成 API。

## 当前证据为什么需要新的监督定义

[旧标签核查](LEGACY_LABEL_GRANULARITY_RESULTS_20261005.md)显示，固定两例的 `b_gold` 精确对应来源 unit 末端；该去噪目标本身不能证明检索收益。[回访诊断](GRANULARITY_REVISIT_RESULTS_20261005.md)中，第一题三种表示最终输出完全相同，第二题仍有参考范围取舍。[父子标签筛查](GRANULARITY_SCORE_CONTEXT_RESULTS_20261005.md)也没有找到预设的判断分歧样例。

这些结果不能认证一个新教师。单块相关性、边界分类正确和修改边界后的下游效用，是三个不同目标；现有 117 项单块 JEV 判断没有直接给出局部 split／merge 操作的效用标签。

## 已有机制的直接重叠

本次限定三组检索，重点核对三篇原始论文；这是机制准入检查，不是穷尽性综述。

| 原始工作 | 可定位的训练机制 | 对本项目主张的约束 |
|---|---|---|
| [Mix-of-Granularity，COLING 2025](https://aclanthology.org/2025.coling-main.384.pdf) | §3.2.2 以证据或 Q+A 与片段的相似度构造软标签，用 BCE 训练查询到粒度层级权重的路由器。 | 查询条件与下游相关监督选择粒度已有先例；其输出是预建层级权重，并非任意局部边界编辑。 |
| [SmartChunk](https://arxiv.org/html/2602.22225v1) | §4.2、G.2 训练 query＋文档元数据到块大小范围的 planner，使用答案正确性、块成本和专家轨迹等反馈。 | 教师反馈、回答效用与成本共同训练粒度已被覆盖；软成本奖励不能直接替代本项目完整渲染的硬上限。 |
| [Recurrent Chunking Mechanisms，ACL 2020](https://aclanthology.org/2020.acl-main.603.pdf) | §2.3–2.4、式 11–12 用正确答案抽取概率训练问题条件下的窗口移动策略。 | 连窗口位置也已有下游回答监督；它不是本项目无重叠文档边界 Refiner，但不能忽略这一机制先例。 |

原文坐标保真、硬预算或局部编辑与上述实现存在区别，不会自动使组合具备新颖性。此处未证实某个精确组合出现过，也不能反向推导该组合尚未被研究。

## 只保留一个可证伪问题

在固定检索器、来源域、渲染器与同一完整预算下，JEV 对一个局部 split／merge 的偏好，能否预测**独立下游效用的变化方向**，并提供原边界先验或查询到粒度层级路由没有的信息？

这是待验证的监督信号问题，尚未建立文献空白或测得效果。不能用教师自己的分数提高来认证其效用；也不能在同两题上继续试验分区直到指标上升。

进入实验前有三个具体条件：

1. **学生能看到什么。** 沿训练 batch、`forward` 与线上推理调用核对 query 是否进入模型。目前不根据方法名称推定这一点。若学生不接收 query，逐问题的教师偏好不能直接称为 query-aware 学习；需要明确查询分布上的聚合目标及同一文档的标签冲突。若选择 query 条件化，应明确修改的是检索前的库分块，还是检索后的候选边界。
2. **编辑是否改变被评价的输出。** 两种边界经过后续选择与相邻合并后，可能得到相同完整证据文本。这时不能把表示差异当作独立的效用信号。第一题的三臂收敛提示了这一风险，但并未穷尽所有局部编辑；未来应记录不改变输出的操作，而非强行赋予有利标签。
3. **教师偏好能否通过独立核验。** 将无改动／原边界先验和已有粒度路由作为简单对照，固定预算及候选曝光范围；分别保留有效、无效和有害操作。若教师分不开这些方向，或普通粒度路由已获得同样作用，就不进入训练。完整渲染与数据可用性也须先成立。

当前只推进第一个条件的零模型接口核查，再定义可辨识的局部干预。没有新评分计划、API 预算、训练准入或效果结论。此前的空筛查和负面结果保持不变；不能用新的方法命名绕过已有机制和证据不足的问题。

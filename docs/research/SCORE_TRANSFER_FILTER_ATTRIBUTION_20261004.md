# 四题缓存归因：JEV 排序与 no 过滤

2026-10-04。复用[固定四题小诊断](SCORE_TRANSFER_MICRODIAGNOSTIC_RESULTS_20261004.md)的全部 64 项判断，完成六组、24 条离线结果。**在相同 `no` 过滤下，JEV 原始 yes 分数排序比 Dense/BGE 排序额外提高平均 Evidence F1 0.125，来自第二题，入选段数相同。** 但过滤本身并非始终有利：它提高了第一题的分数，也排除了第四题的参考段落。

这是看到主结果之后制定的事后分析，不是独立验证，也不替换原有三组主读数。本阶段 API 调用、模型推理和新增 API 费用均为零。

## 哪些作用能够区分

- **题 1：过滤足以复现主组选集。** 过滤后只剩两个候选，三种排序选出完全相同的两个段落。JEV 不过滤时保留这两个参考段落并多选一段，F1 为 0.8；过滤后为 1.0。这里无需数字排序即可获得主组结果，但相对原 Dense/BGE 的变化也包含补入参考段落，不能只称“压短了包”。
- **题 2：数字排序提供额外参考命中。** 过滤后仍有六个候选，三种排序均选三段；Dense/BGE 为 0，JEV 为 0.5。JEV 包比过滤后 Dense 多 54 tokens、比过滤后 BGE 少 67 tokens；段数相同，不是长度匹配实验。JEV 不过滤与过滤的选集相同。
- **题 3：换包而指标不变。** 过滤后的 JEV 与另外两种排序选集不同，但均为 0；可回答参考段落不在池中。此前观察到的语义限定损失仍保留，F1 平局不代表内容等价。
- **题 4：硬过滤排除了精确参考段落。** 不过滤的 JEV 排序能选到该段，F1 为 0.5；过滤后仅剩一个候选，三种排序均为 0。该段的既有判断是 `no`，原始 yes/no/unknown 为 .35/.53/.12。原问题与参考主题的解释分歧、不可回答备选注释都保持原样，不能仅据此宣称模型语义判断必然错误。

固定过滤后，JEV 分数排序相对 Dense 和 BGE 的逐题差均为 `0,+0.5,0,0`：平均 +0.125，四题段数全相同，两题选集完全相同，两题选集不同。相同排序下，过滤对 Dense/BGE 的平均影响均为 +0.150，对 JEV 分数排序则为 −0.075，后者逐题为 `+0.2,0,0,−0.5`。

原主差 +0.275 可以沿“BGE → 过滤后 BGE → 过滤后 JEV”分成 +0.150 与 +0.125；沿“BGE → 未过滤 JEV → 过滤后 JEV”则是 +0.350 与 −0.075。这种分解依赖路径，不是收益的固定因果比例，也不能把过滤与排序视为互不相关的贡献。

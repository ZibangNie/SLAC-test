# 六个固定自然交换的生成模板预算诊断

2026-10-04。按[执行前协议](NATURAL_GENERATOR_BUDGET_PROTOCOL_20261004.md)，保持已有六题、十二个 S/T 包、全部文本、成员、顺序及预算不变，只比较三种完整证据渲染。**生成模板增加了 197–212 个 BGE token，但 12/12 个包仍满足原 1,024 上限，四种历史判断读出的 24 个选择全部不变。** 因此，当前固定投影下的预算开销不能解释或修复此前 JEV 对唯一共同正例的拒绝。

新增 API、模型推理、训练、密钥读取、问题与语义判断均为 0；使用了已有的本地 tokenizer。没有扫描全数据集，没有生成答案。这里只诊断冻结检索文本的渲染与 BGE 代理预算，不是 Refiner 端到端效果或真实生成模型的用量测量。

## 身份检查与固定投影

六例涉及三篇已曝光文档，与此前来源适配所用的两篇 Refiner 文档，文档 ID 交集为 **0**。所需唯一 `(doc_id, unit_id)` 共 23 个，全部没有现成的对应 Refiner 来源。冻结 packet 中 native/retrieval 文本 SHA 字段 23/23 相同，且 retrieval 字符串匹配其摘要；这不构成 Refiner 字符区间或 atom 来源认证。

因此没有拼接新的来源映射，也没有把旧段落标签迁移到新粒度块。实际 [`render_evidence_block`](../../SLAC/llm/service/renderers.py) 使用保留 passage 的政策，字段只来自现成记录：单元 ID、文档 ID、完整冻结文本、question ID 和 query。排名、路径、角色、分数、逐段估计、views 等均未补入。顺序保持原 source order，不当作检索 rank。

这是一个预先声明的最小字段投影。它没有运行 `FinalIntegrator` 的候选规范化、来源恢复或选择器，也不代表该模块的所有 metadata 配置。

计数器是原研究固定的本地 BGE-M3 fast tokenizer，包含 special tokens、关闭截断，本地加载且禁用 remote code。五个 tokenizer/config 文件均绑定 SHA256；没有载入神经模型运行时或权重。主执行共进行 36 次整串计数，没有按单段相加。

## 核验与研究判断

公开执行脚本为 [`probe_natural_generator_budget.py`](probe_natural_generator_budget.py)。运行前绑定协议、八项源码/文档、五项既有输入、五个 tokenizer 文件和运行时版本；结束时重核输入与源码。保存的原问题、文本、字符串、请求和完整 payload 均留在私有目录，仅发布[匿名结果与绑定](results/natural_generator_budget_20261004.json)。

本轮没有修改生产算法或重复整套测试。独立审计检查固定文本、最小字段投影、完整渲染与已有计数，并复算保存字符串及历史动作；其具体执行范围记录在机器结果中。compiler 序列化行为以主执行记录和源码为证据，不把只读核对称为新的模型运行。

按预定规则，**结束当前投影下“模板预算解释旧拒绝”的分支**。这是一项有边界的否定结果：模板开销是真实的工程问题，但在这些固定包上没有产生选择差异。BGE 计数也不包含 system、query、memory、provider framing 或输出，不能认证生成模型的完整上下文、计费或答案质量。

后续应以语义机制和实际 SLAC 分块模型的未解问题为准，而不是继续给这六例增加 metadata 或调上限。此前[需求范围审查](QUERY_OBLIGATION_AUDIT_20261004.md)及[来源机制筛查](SLAC_SOURCE_MECHANISM_SCREEN_20261004.md)已经否定了简单改写问题、添加来源标签即可形成新贡献的做法；保留这些结果，避免重开同一分支。当前依然没有新的自然 RAG 收益或论文创新性证明。

一个尚未验证的具体问题是：已有训练好的 Refiner 是否在固定两文档上产生不同于 native 恒等边界和仅规则投影、且约束投影后仍保留的边界变化。[此前两文档接入](NATIVE_REFINER_GRANULARITY_RESULTS_20261004.md)只执行了 `b0_identity_fixture`，没有模型边界预测。下一步先核对 checkpoint、encoder、输入及训练配置兼容性；只有证据充分，才对同两文档进行一次固定本地推理，分开保存模型预测和规则投影的贡献。边界不同只是机制差异，不代表质量提升，也不自动触发 JEV 调用或训练。

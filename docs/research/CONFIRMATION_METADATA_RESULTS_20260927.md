机器解析、被选择导出、持久化 QA、进入模型、用于评分/调参以及人或 agent 实际看见内容，是不同渠道。对剩余文档，只能确认其不在已绑定的 32 篇导出名单内，不能证明所有外部工作均未使用过。模型预训练暴露仍未知。新元数据阶段没有打开 archive、QA sidecar、官方 test、canonical 正文或 legacy 文本；旧内容核对仅继承其既有承诺，未伪称重新读取全量内容。

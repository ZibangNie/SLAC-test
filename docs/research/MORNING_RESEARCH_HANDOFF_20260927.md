## 当前关系规则的结论应停止在哪里

本轮窄规则是在 B 已选时，按静态有向依赖为原生前驱 A 增加一次 +1 优先级；它不是新的Refiner，也没有进行跨阶段 I/C/S 共享干预。

1. 全部501种允许赋值中，只有17/77题可能改变最终证据包。完整可达输出共96个不同query–pack；额外14次生成完成后，所有保存响应均可重放。全邻接相对无关系 I 的答案双区间跨零。逐题选择保存响应中的最大F1，均值为0.505481 / 0.552162，仍低于score的0.513325 / 0.559005；这只约束**本规则和这一组保存响应**，不是新生成的期望上界，也不是可部署选择器。[全可达包结果](RELATION_PACK_ANSWER_RESULTS_20260927.md)
2. 预先冻结的原域placebo在76/77题上与content函数完全相同；仅1题、4/501赋值可能区分。该对照不是完全退化，但语义区分能力很窄。不得见结果后换seed、放松strata或删题。[原域符号结果](RELATION_PLACEBO_DEMAND_RESULTS_20260927.md)
3. 联合需求的20条JEV单例均成功：7 dependent、13 independent、0 unknown；这不是完整562条的标签分布。七方法×77题=539条记录及24区间已独立复算，所有答案精确继承，新增生成调用为0。
4. Content Answer F1为0.474248 / 0.519769。相对R0差值为 **−0.009839552 [−0.024602265,+0.000057391]** / **−0.007036084 [−0.017723314,+0.000087283]**，1增、74同、2减。很小的正上界仍是跨零，不能四舍五入成全负。Content与placebo在全部77题的包及保存预测完全相同；零差区间来自相同预测，不是统计等效证明。其他所有非placebo答案比较也跨零。[实际内容结果](RELATION_CONTENT_EXECUTION_RESULTS_20260927.md)、[全部精度JSON](results/qasper_relation_content_20260927.json)

据冻结的停止规则，**停止当前“+1邻接依赖带来语义内容收益”的主张**。不把它推广为所有关系定义或JEV无效，也不以新增模块、换随机种子或训练Refiner补救这个负结果。完整562任务阶段仍未准入，不因20条成功而自动重启。

## 最后一个控制已完成：省读主要来自激活过滤

已完成的有限函数编译发现101条eligible唯一边中19条必要，且19次题边出现没有跨题重复；逐题空缓存最短与最长深度相同。这支持静态剔除，不支持已观察到的空缓存自适应节省或跨题共享收益。直接lazy selector另在501 / 23,915路径上保持精确输出，记录326 / 9,682次逻辑读取及22 / 70次非必要读取。逻辑读取不是HTTP调用、费用或系统时延。[编译结果](RELATION_DEMAND_COMPILATION_RESULTS_20260927.md)、[lazy结果](RELATION_LAZY_BOUNDS_RESULTS_20260927.md)

当前图中，每个已选B至多激活一个前驱A，预算或重复跳过不会激活新边。达到k=3后立即终止，因此任何只读未知active边且不重复问边的策略天然最多新读k−1=2次。若提前止于r<k，最多可读r次而不是r−1。不能把max2归因于区间证书。

新[activation-only控制](RELATION_ACTIVATION_CONTROL_RESULTS_20260927.md)固定“先问齐全部未知active边，再精确选winner”，相同501 / 23,915完整路径的正式run、回放audit及独立新实现核验均完成。空缓存读数为eligible 2,166 → activation 352 → lazy 326；全known-subset为76,390 → 9,760 → 9,682。激活过滤分别省1,814 / 66,630读，区间证书另外省26 / 78读，绝大部分差距来自前者。26 / 78条路径各额外省1读，其他路径无额外节省；非必要读仍为22 / 70。全部winner轨迹和精确包相同。以上是完整有限域逻辑计数，不是概率、API收益或部署时延；使用255个已验证整包token记录重放，没有新增分词，也不使用另一个付费阶段的20条真实关系标签。独验receipt为 `629481aeae67a11c496de3c8cfba8a190b792789ccea99f67e2ea55e68f95896`，40绑定与全部公开聚合复核一致。

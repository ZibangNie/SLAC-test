2026-10-04。继[四题事后归因](SCORE_TRANSFER_FILTER_ATTRIBUTION_20261004.md)之后，在另一份既有开发缓存中固定抽取六个 family、每个一题。**开启与关闭 `no` 过滤的六对证据包全部相同**：两臂平均 Evidence F1 均为 **0.2445887445887446**，逐题差值全部为零。新增 API 调用、API 费用、模型推理和密钥读取均为零。

这批样本没有实际选包对照，因此没有支持过滤有效或有害的新证据。按预定 `all_tied_same_packs` 分支收尾，不更换 salt、不扩样寻找差异，也不修改既有主方法。

## 抽样与两臂

在读取本次所选标签、分数和参考前，固定 salt `slac-hard-no-cache-20261004-v1`。对原 24 个 family 按 `sha256(salt|family)` 排序取前六个；每个 family 内按 `sha256(salt|family|doc|qid)` 取第一题，同 hash 以原字符串元组解平局。只用身份元数据选题，保留原候选数，不因不足 16 而补候选。

原缓存共 77 题，已被多轮开发使用；本研究问题也是看到四题结果后提出的。虽然六题与此前四题的题目及文档身份均无重叠，这仍不是独立确认、随机总体估计或未曝光测试。两轮结果不合并成一个新均值。

两臂共享原始 yes 分数排序、Dense 次序平局规则、原候选池和打包函数，仅切换是否排除 `choice=no`。最多三单元、整个包 1,024 tokens、精确原文去重、超预算跳过继续及原文顺序渲染全部保留。没有新增阈值、k 或其他排序。

## 计算与范围

先固定六题和 94 项输入，再封印全部十二个证据包，随后才解码六行原参考和六行历史 `p_yes_only_k3` 指标。原 JSONL 其他行只用于摘要及字节定位，没有逐行 JSON 解码或语义审查；仅核验所选 94 项标签／分数，没有重审整个 1,214 项模型响应。匹配出的六行参考另存供窄复核。

原过滤方法的六个选集、pack hash、tokens 和逐题指标全部复现。保留所有原注释、不可回答选项及官方最大 F1 规则；交集按唯一原文字符串，分母仍用原始列表长度。少量合成行为检查覆盖重复参考分母、空—空、精确去重、整体非可加 token 预算及所选值投影。没有生成答案或计算新 Answer F1。

独立核验重建所选 94 项判断绑定、十二条排序／打包与六个不同证据包的整体 tokens，并只用已保存的六行参考、十一项注释以有理数复算 F1。逐题精确值为 `1/2, 2/11, 1/2, 0, 0, 2/7`，与浮点指标在 1e−12 内一致。原六项基线与固定决策也通过核验；复核没有重新打开原参考全集或扩充测试样本。

## 研究决定

本阶段关闭“继续抽样寻找硬过滤作用”的推进路径。四题中的具体反例继续保留，但它尚不足以形成新的自适应过滤器，更不能以模型较新为依据宣称算法创新。当前没有从本样本推出新的阈值、训练任务或付费扩样计划。

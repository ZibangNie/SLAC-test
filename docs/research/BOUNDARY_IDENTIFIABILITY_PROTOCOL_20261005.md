# 固定 atom 域下的边界编辑：表示能力检查

2026-10-05。只检查一个集合包含命题，不搜索更高分的分块策略，也不读取自然数据。上一阶段说明实际生产 metadata 会随分区改变；本检查显式采用研究用的规范来源区间渲染，不能自动推广到默认生产链路。

固定原文、atom 坐标与可见来源域。合法块只能由同一连续来源分量中的相邻完整 atoms 组成，不能切开 atom，也不能跨不可见缺口补文本。选中任意完整候选块后，合并 touching source spans、按来源排序，并仅由最终 span 赋稳定 ID。doc/query、renderer 及其他可见字段固定；禁止携带分区序号、评分或路径等额外变化。约束仅为最终 run 数 R 和完整 evidence block 的成本 B，没有候选 item 数上限或选择过程中的前缀可行性要求。

待检查命题：粗分区的每个可行输出都可由其任一细化分区复现；全部 atoms 单独作为候选时，已包含任何合法分区能产生的输出。这是可行表示集合的性质，不是评分、贪心搜索、时间／调用成本或真实效果的支配关系。

执行前固定两个各含五个 atom 的人工输入：

- 连续例：source 为 `a b c d e`，atom 区间为 [0,2)、[2,4)、[4,6)、[6,8)、[8,9)。
- 缺口例：source 为 `a b |gap| c d e`，atom 区间为 [0,2)、[2,4)、[10,12)、[12,14)、[14,15)；[4,10) 不在候选域，所有合法分区都必须在这里断开。

每例只枚举这五个 atom 的合法分区及完整块子集，保留全部结果，不按结果换输入。这是最多五个 atom 的有限合成状态检查，不是数据集扫描。将基于块的选中结果与直接 atom 选择产生的规范输出逐一比较；对每个粗／细分区对核对包含关系。

使用真实 `merge_spans` 与 `render_evidence_block(..., preserve_source_text=True)`，ID 使用 `span-{start:05d}-{end:05d}`，与既有研究渲染形式一致。不运行 tokenizer；有限检查的成本明示为完整 UTF-8 **字节数**，预算固定为 0、512、4096 bytes，R 固定为 1、2。它们不是 token 预算或账单估计。一般证明若成立，应适用于任意仅依赖相同最终输出的成本函数，不要求 token 成本可加或单调。

另外固定唯一一项反例：source=`ab`、两个 atom、pre-merge item cap=1。比较一个粗块与两个细块能否输出 `ab`。它检验移除假设后的失败，不是对自然数据的效果实验。

源码与 fixture 在执行前封印。API、模型、tokenizer、训练、自然记录和参考读取为零。检查不认证任意新的切分点、跨域扩展、上下文评分或有限搜索算法。若等价成立，后续研究必须把效应放在明确的评分上下文或有限资源搜索上；不能仅凭改变边界宣称增加了 all-atom 基线的证据表示能力。

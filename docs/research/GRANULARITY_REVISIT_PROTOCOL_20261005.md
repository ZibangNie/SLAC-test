# 原约束下的末态预算与回访诊断

## 先检查六个独立加入

固定上一轮 `final_geometry.json` 中最终段数不超过三的全部六项，不按参考、语义判断或分数删选。每项独立加入原 `cap3` 的 C 包；仅合并接触区间、不补空隙。使用原完整 renderer 与已封印的本地预算 tokenizer，计算原包和拟选包的完整 tokens。六个拟选包先封印，再汇总段数、来源长度、预算是否可行；此步骤不读参考、不累计加入或修改原预测包。

如果六项都不能满足 1,024 tokens，则记录结果，本轮不实现回访政策。如果至少一项能满足预算，则说明原单次扫描的最终包不是单项加入意义下的极大可行包，可以进入以下受限诊断。该门槛只依据来源几何与完整预算，不依据参考覆盖。

## 条件成立时的固定回访政策

在 A 完整单元、B child-max 父单元、C atom 三臂全部采用同一政策。第一轮必须精确复现原 `cap3` 的 chosen、runs、trace、完整渲染与 tokens。随后反复按原评分顺序扫描尚未入选项：分数降序、Dense 父排名、原文起止位置；每次拟选包仍要求最多三个输出来源区间、完整渲染不超过 1,024 proxy tokens。拒绝后继续扫描，一整轮没有新增才终止。

每次接纳都增加一个此前未选的候选；不删除、替换、重打分或过滤 no/unknown。输入候选有限，因此在有限轮内终止。预算计数不假定可加或单调；不跳过先前因 tokens 被拒的项。不采用轮数网格、语义阈值、gold 引导的候选优先级或跨空隙补文本。

该政策只保证在终止包上没有单个剩余候选可在原预算内加入，不保证全局最优，也不保证联合加入或替换不存在更优解。来源字符只能增加，所以已选参考字符不会减少；这种由构造带来的覆盖不下降不能作为质量创新证据。更多低分内容可能损害回答，实际 token 数也未必随字符数单调增加。

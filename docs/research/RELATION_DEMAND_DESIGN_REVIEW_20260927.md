# 按需问边：决策图表述与对照边界复核

2026-09-27。只读设计审阅；不实现算法、不读取质量结果、不产生标签或 API 请求，不修改[原实验草稿](NEXT_RELATION_EXPERIMENT_DRAFT_20260927.md)或[501-mask 机会协议](RELATION_OPPORTUNITY_PROTOCOL_20260927.md)。以下数学结论是对所提设计的推导，尚不是实现审计或新实验结果。

**建议定位：将已冻结 selector 编译为 pack-valued ordered decision diagram，在固定标签 oracle 下按需读取关系。** 可研究的价值是这一应用的全赋值等价保证及实际调用开销，而不是新 BDD 算法、关系语义已有效或答案质量提升。

## 经典方法已经覆盖什么

Bryant 的经典有序决策图使用固定变量顺序，通过消去两个后继相同的节点、合并相同子图进行约简；固定顺序下有规范表示，但图大小可能随顺序显著变化，最坏情况仍可指数增长。本文所述按剩余函数判断变量必要性、复用相同子图，属于这一类既有构造思想，不能据此宣称新决策图算法。[Bryant 1986，作者提供的带注释原文，定义与约简见第 2 节](https://www.cs.cmu.edu/~bryant/pubdir/ieeetc86.pdf)

有限多值终端也不是新增概念。Bahar 等关于 ADD 的论文明确将终端从 Boolean 值扩展到任意有限值域。因此，将每种规范 pack 编码为一个终端，可描述为经典有限多终端决策图的应用；这不意味着使用了其数值代数运算，更不应把 pack 终端本身写成新算法贡献。[Bahar 等 1997，官方出版社摘要](https://link.springer.com/article/10.1023/A:1008699807402)

本审阅仅依赖这两项一手技术来源，没有用二手综述替代原方法，也没有引用未读的全文结论。

## 等价性应精确限定到什么

对固定问题的冻结输入 `I_q`，令 `F_q(z)` 输出最终规范 evidence-pack 字节，`z` 是固定 eligible 邻接域的 dependent 激活位。只有 selector 将 independent/合法 unknown 都映射为不激活时，二值 cube 才覆盖其 pack 行为；失败、超时、缺失响应不能冒充合法 unknown。

```text
全局无关边 e：对所有其他位的赋值，F_q(z[e=0]) = F_q(z[e=1])。
给定前缀 p 后的条件无关边 e：受限函数的两个 cofactor 完全相同。
执行要求：对全部 assignment，DAG_q(z) = eager_F_q(z)。
```

条件必要性必须比较**所有未读位的剩余函数**，不能只看一个默认补全、零 mask、全 mask或两个分支的输出集合是否相同。两个子函数可以拥有相同的终端集合却将不同赋值映射到不同 pack。应以完整 cofactor 或已经正确约简的子图身份比较。

固定 native 顺序有利于重放；它不保证最少节点、最少平均读边、最低 API 费用或最短延迟。终端等价应绑定完整 pack 字节及所需输出合同，hash 只是可核对的指纹；若研究还声称 acquisition trace、bonus/priority 事件相同，应另行验证，**相同最终 pack 不推出相同过程 trace**。

单题全 cube 等价蕴含对其真实固定标签赋值等价。跨题缓存仍必须保证同一 document-edge 在所有题上读取同一个 oracle 值；逐题 cube 并没有证明所有 mask 能同时成为同一文档的全局标注。某边对一题无关，不等于可从其他题或全局缓存中删除。

## content 必要边不能直接取代原 placebo 标签域

原草稿的 placebo 在每题完整 `E*_q` 的固定 strata 内，置换已得到的标签以保留层内 positive 数及原定类别/触发分层。**对 `F_q` 无关的源边，可能通过置换成为必要目标边的标签来源。** 这是本设计最重要的对照风险。

```text
F(a,b) = a             # b 不影响 content 输出
P(a,b) = (b,a)         # 同层固定交换
F(P(a,b)) = b          # b 却决定 placebo 输出
```

因此只按 content 的 DAG 问边，不能恢复原完整层的 dependent/independent/unknown 计数，也不能默认得到原 placebo pack。adaptive 路径所读子集还依赖已见标签；把这个子集当作原层总体，会改变 null 和计数分母。未读边应记为未观察，不能补成 independent、unknown 或 no。

未来若保持原对照，应验证 **`F_q ∘ P_q`** 所需信息以及原 strata/标签统计的覆盖，连同各臂一起确定请求域；如果为了省调用而改变 placebo 域或匹配规则，就必须冻结并公开新的 null 和覆盖合同。即使最终 pack 可用更少标签求出，也不能声称完成了原 **562 个静态标签**阶段，或把旧完整标签统计/机会分层结论自动搬过来。需要哪些边由目标函数和统计合同共同决定，不由 content pack 单独决定。

## 固定 oracle 与真实 API 是两层问题

| 可以证明或核对的对象 | 不能自动推出的结论 |
|---|---|
| 同一份冻结标签缓存下，全部 assignment 的 pack 等价 | 模型对关系判定正确，或该关系会提升答案 |
| 读取更少逻辑边 | 发出更少 HTTP 请求、花费更低、延迟更短 |
| 单条边文本相同 | singleton、不同 batch 同伴/顺序或不同请求配置会返回相同标签 |
| 本候选/support/packer 下的约简 | 新候选、support、正文或预算下仍可沿用原图 |

即便模型名、temperature 或判断文本相同，改变 batch 上下文也没有标签逐项恒定的保证。旧 batch 的部分标签可以作为明确来源的固定 oracle 数据使用，但不能声称它等于未执行的 singleton 响应。跨题语义缓存与完整请求字节相同的响应缓存，也应分别登记。

若未来做 eager 与 demand 的调用实验，应明确是**同一固定 oracle 的访问模拟**，还是两个实际 API 请求策略。前者只支持标签访问节省；后者可能同时改变标签实现，不能只用编译等价证明保证相同结果。新协议需锁定 payload/batching/provider/实际模型及错误规则，记录实际请求、输入输出 tokens、费用/未知、缓存冷暖与编译成本，不能仅把读边减少数换算成端到端收益。

## 重新编译及最小放行条件

以下任一输入改变，都应使旧编译绑定失效并重新构建/核验：候选身份或原文、support 标签及 eligibility/base score、邻接/方向、dense/source tie order、去重、selector/bonus、k/budget、完整渲染、tokenizer 或 token 计数语义。顺序改变也需要新编译与成本基准。只改变关系位的实际取值仍在已枚举函数域内，但新模型/batch 得到的标签属于新的 oracle realization，不能继承旧标签实验的结论。

后续最小科学要求是：

1. 对冻结输入的全部 501 个逐题 assignment 核对 DAG 与 eager 的完整 pack 等价，保存源绑定；不给 gold、答案或质量指标进入构图与顺序选择。
2. 内容、全邻接、independent、原 placebo 各自的信息需求与分母明确；如果原 placebo 不可完整重现，先修订控制协议，不静默只评估已问子集。
3. 把 fixed-oracle 等价、逻辑访问数、真实请求费用和质量效果分开报告。没有新质量实验时，只能报告编译/访问行为；即便将来观察到质量效果，也不能将经典约简本身或模型发布日期视为创新证据。

本审阅没有计算或选择真实必要边数、标签分层、最优顺序、费用收益或质量差值，也不构成静态 API/生成阶段的准入。

# 三臂分析入口与评分来源契约

2026-10-05。本入口落实[三臂修订](GRANULARITY_PARENT_CONTROL_20261005.md)的选包和评价顺序。**本轮没有 fresh scores，没有运行自然样本分析，也没有新增质量结果。** 旧两臂协议、失败运行、117 个冻结配对及其准备记录均保持不变。

## 分析的固定范围

只允许原两题的 30 个完整 source Unit、97 个 source atom 和 117 个唯一 query/passage 输入。A 为完整单元直接评分与输出；B 用新 child 分数最大值评分完整父单元并输出父单元；C 为 child 直接评分与输出。它们复用原 `select_ranked` 的同分规则、单次扫描、相邻来源区间合并、三段及 1,024 BGE proxy-token 上限，不改为跨空隙扩展或截断。

新入口接受固定阶段目录下的一个直接子目录作为 `--score-dir`，以及尚不存在的直接子目录 `--output-dir`。不覆盖旧目录，不追溯载入完整语料。旧评分 runner 还没有产生本入口接受的新分数格式；将来须在明确运行协议下生成或适配完整分数及其来源，不能仅把旧失败目录改名。

## 分数来源必须成立

输入 `scores.json` 的 schema 为 `slac-granularity-direct-scores-v1`，包含冻结输入文件 SHA256，以及全部 117 条唯一 `task_id`、query SHA256、passage SHA256 和有限实数 `raw_logit`。逐条对照固定 query/passage 字节，不接受缺项、重复、额外任务、布尔值或非有限分数。

`summary.json` 必须说明 `status=completed`、`provider=local_bge`、`score_kind=raw_classification_logit`、两题 117 配对的输入绑定及 `scores_sha256`，同时记录实际执行 contract；`references_read=false`、`api_calls=0`。`run_manifest.json` 用 `scores_sha256` 和 `summary_sha256` 绑定成功输出。哈希链只验证记录与字节一致，不能自行证明任意外来记录的真实性，因此仍需评分运行器和执行收据。

模型固定为 `BAAI/bge-reranker-v2-m3`、revision `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`，禁止截断。接收的设备／精度组合仅为 `cuda:0/float16` 或 `cpu/float32`，报告必须保留实际组合。这项格式兼容不代表 CPU 计划、推理或性能验证已经完成；本轮两种执行都没有发生。

本入口只接受上述本地 BGE 契约。JEV 的判断标签、yes 分数、缺失值及批量响应有独立语义，不能改一个 provider 名便按 BGE raw logit 解释；若后续开展 JEV 比较，必须独立明确对应规则。

## 先冻结全部预测，再评价

选择阶段不读取参考文件。先保存六个完整包、B 的最大贡献子项及所有并列项，然后封印输入、分数、源码、完整渲染和策略。随后才打开同一已保存的四份参考区间；两题均保留所有 annotation，不挑选或合并答案范围。

报告全部十二条 annotation×方法的来源字符交集、precision/recall、完整覆盖、来源字符数和完整 evidence block tokens；同时保留原候选域覆盖上限，并比较 A/B、B/C 的来源集合和渲染差异。公开报告只含序号、聚合计数及哈希，完整正文和真实身份保留在私有输出。字符覆盖不是语义充分性、原段落 Evidence F1 或 Answer F1。

这两题已经曝光；相同上限也不保证相同实际上下文长度。max 的子块数偏好、评分上下文差异和贪心前缀可行性仍需保留，不能用入口通过或单例改善证明 SLAC、learned Refiner、JEV 或新算法收益。

## 不依赖本机显存的 JEV 路径：只完成离线可行性检查

另用[请求检查脚本](inspect_granularity_jev_wire.py)将同一 117 个冻结 query/passage 配对送入已有客户端的纯请求构造函数，按题分组、每批最多八项，禁止截断。没有实例化带凭据的客户端、读取 key、访问网络或发送请求；往返 JSON 校验确认完整 query/unit 文本不变。没有增加样本或恢复旧付费计划。

这项检查解决了“既有两题是否能装入有界 JEV 请求”的问题，没有建立执行计划或验证模型输出。下一步若选择该路径，需要核对当前官方模型／接口／价格，单独固定 JEV yes 报分、unknown、过滤和 parent-max 的解释，并建立完整评分才评价、首次失败停止、不重试的短时限执行记录。JEV 分数不能送入上述 BGE-only 入口冒充完成原实验。

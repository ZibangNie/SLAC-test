## 这个结果改变什么

此前[六个自然问题的探测](NATURAL_EXCHANGE_JEV_RESULTS_20261004.md)在第 1–3 例上将损失判为 yes，与两份原文评审不同。[离线诊断](NATURAL_LOSS_SCOPE_DIAGNOSIS_20261004.md)发现，被删事实与原问题的关系涉及主体、任务和用途范围。

本轮说明，不能简单把那种表现解释成“模型只要看到事实被删就固定判 yes”：证据不变而提问更明确时，这两对可以得到不同判断。不过，问题的词汇和目标也一起改变了，本轮无法把语义范围理解与词面线索等其他因素分离，不能定位旧输出的内部原因。

**不能把旧自然问题的 gain=yes 与新改写问题的 loss=no 拼在一起，宣称救回了原交换。** 两者针对不同 query，绑定和信息需求不同。尤其第 2 个自然问题询问完整基线范围，而 Q4 只询问三类嵌入对象；缩窄问题可能遗漏原来需要的信息。

同样，上一轮“不完整见证清单不能证明整包无损”的结论仍成立。这四次输出既没有补齐自然问题的全部相关陈述，也没有证明问题自动改写后的范围覆盖。

下一步回到零 API 分析：检查从原问题形成明确判断目标时，是否保留了主体、任务、限制条件和全部需求；把遗漏原需求的缩窄当成失败，而不是因为更容易得到 no 就接受它。仅在能提出有依据的算法假设后，再决定是否值得进一步小规模验证。当前没有新的选择算法收益或论文创新证据，不因 2/2 的结果扩大调用。

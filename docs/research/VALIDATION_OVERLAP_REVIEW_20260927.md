# 唯一validation–train重叠标记的文档复核

2026-09-27。仅复核[249篇筛查](REMAINING_VALIDATION_SCREEN_20260927.md)产生的唯一中等标记，原数值精确重现。现有证据支持“两个不同元数据身份的文档存在分散的共同措辞，需要版本/来源复核”，**仍不能判断同一论文、污染或泄漏**。这是AI辅助的机器文档review，不是人审；没有自动排除、family合并、holdout选择或准入clearance。

只解码哈希绑定的canonical validation/train两行，并核对两行均未导出或解码QA。gzip流中的其他正文行仅跳过、不做JSON解码；元数据index先验证只含train/validation。没有打开QA、答案、原始档案或test文件，也没有向web或外部API发送论文信息。真实ID、标题、section名称与词位置/原生块字符范围只保存在本地忽略目录。

共享唯一5-gram为 **3,511**，Jaccard **0.2496444824**，validation containment **0.4134966435**，train containment **0.3865037428**；与冻结flag完全相等。这些比例衡量唯一词组集合，不能解释为同样比例的原始字符、段落或答案泄漏。

两个文档的声明family、source ID与arXiv基础ID均不相同；canonical全文、正文原文、归一化正文及原始来源hash均不同。两者都没有可用的显式版本字段或source ID版本后缀。上述结果排除了本表示下的逐字相同文档，**不能排除不同ID的相关版本、扩展论文或共同来源**。

最多的单个section在两篇中各涉及516个共享唯一5-gram；不是只由一个section贡献全部重叠。没有标题被规则归为references/bibliography，共享5-gram也没有命中所检查的 `BIBREF/INLINEFORM/DISPLAYFORM` 占位符。**这没有证明所有参考文献、公式或模板都被识别了**，更不能把“方法/模型标题”直接当成人工确认的技术内容复用。尤其validation近一半共享词组落在未分类标题，仍需查看私有定位材料后判断。

最长连续相同的NFC/casefold词序列为 **93词**，在两篇中均位于一个未分类标题下的块；分别约占正文词数1.08%和1.01%。此处忽略大小写和标点，不声称93词对应字节完全相同的原文片段。完整非空块经相同空白归一化后，仅有 **2种共同块文本**，两篇各出现2次、合计50词。它们支持局部共同文本的存在，不能把3,511个共享词组当成3,511个独立复制事件，也不足以确定作者关系或复用原因。

## 哪些解释仍待证明

- **单纯参考文献造成重叠：** 当前heading定位没有提供支持；但canonical抽取范围与分类规则有限，仍不能排除未识别引用/模板成分。
- **多个正文位置有共同措辞：** 精确词组交集、跨多个section的定位和93词连续匹配提供直接证据。是否属于通用表述、方法沿用、共同来源或版本扩展，尚未判定。
- **同版本、泄漏或训练污染：** 不同身份/hash不能完成版本归并；共享正文也不能证明特定问题/答案暴露、评测捷径或模型训练使用。需要人工结合原始来源与版本历史，并在未来单独授权的数据准入流程中验证，不能从当前机器flag直接推断。

保留该pair为待审，维持全部249篇原始名单和原有“未获准入”状态。下一步应先有人审阅私有section/词段定位并记录来源判断；本次没有外部查找作者/版本，也没有借机读取QA或扩大到其他文档。

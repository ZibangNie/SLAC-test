# SLAC × JEV：零 API 路由实验结果

2026-10-04。**当前四个廉价特征没有带来路由增益，预先定义的结构特征判据未通过。** 同样在 37/77 题上选择 JEV 时，四特征模型的题等权 Answer F1 为 **0.437245**，低于单特征模型的 **0.443485**，也低于同配额随机策略的精确期望 **0.474509**。按[冻结协议](CACHED_ROUTING_PROTOCOL_20261004.md)停止这组特征假设，不根据这些结果加特征、换折、改惩罚或调配额。

这是一项新完成的缓存实验，不是新一轮模型调用。两个完整答案端点继承此前已审计的 BGE 和 JEV 原始证据包及回答，生成器均为 `qwen/qwen3.6-plus`。本阶段 **API 调用、密钥读取、答案生成、新 900 题参考读取均为 0**。结果仍来自已暴露的 77 道开发题和 24 个原始 family，分组交叉验证不使它变成独立确认。

随机行所有分数、证据长度和判断数均是每折均匀选择固定数量问题的精确期望，没有生成一个随机选集再挑结果。所有策略保留全部 77 题。常规路由每折使用 `floor(N/2)` 个名额；五折题数为 **15 / 16 / 16 / 15 / 15**，合计 37 个名额。

唯一主增量比较“四特征−单特征”的题等权差为 **−0.006241**，family 等权差为 **−0.021995**；题级胜／平／负为 7 / 66 / 4，family 级为 6 / 14 / 4。小幅胜出次数较多并不能抵消下降幅度，因此不能只引用胜率宣称有效。四特征相对随机期望的对应差值为 **−0.037264 / −0.043686**，同样未达到判据。

四特征相对全 BGE 的题等权差为 +0.000098，但 family 等权差为 −0.000983；本次没有显著性或非劣效检验，不能把接近的数值解释成质量保持认证。全 JEV 的既有正向开发信号仍保留，本结果只说明当前廉价特征和固定模型未成功识别应优先使用 JEV 的问题。

## 数据流和验证

四个调用前特征为完整候选池的 BGE 间隔、Dense/BGE 原包分歧、BGE 包来源跨度和标题比例。没有把 JEV 标签、分数、选包、参考答案或答案差值加入推理特征。四列均非恒定，没有因为某列弱而更换定义。特征与 family 折分先独立保存并绑定，再读取两组完整答案的质量字段。

五折按 family 整体隔离；训练集每个 family 等总权，均值和方差只在训练部分拟合。固定系数惩罚为一，截距不受惩罚，没有超参数搜索。10 个主模型完成预测后先保存路由决定，再汇总测试质量。额外的五次测试目标整体替换检查均通过：每一题的目标确实被改变，而该测试折的模型、预测及选择保持完全不变。

核心算法、特征准备和缓存执行分别通过 **61、15、17 项合成测试，共 93 项**。独立实现使用标准库增广正规方程核对 128 个合成回归模型，并检查折分、配额、随机期望及目标隔离。

真实数值复核沿用固定的 **8 个 family、14 题**：56 个特征值、28 个 Dense/BGE 包哈希、28 个预测、42 个确定性路由动作和 84 个策略分数／资源记录均一致。样本自然覆盖四折，没有为覆盖第五折或结果变化题而补样；相应八个训练模型由独立求解器重新拟合。全体身份、计数、哈希及折分做机械完整性检查，没有重新逐条审查原模型响应或所有数据内容。

两处纯合成检查发现的问题均在首次真实质量运行前修复：方差数值下溢时按协议置零；随机期望用保留相同端点值的运算形式，避免浮点残差制造虚假的胜负。没有为真实结果调整 tie 容差。

## 框架产物与成本边界

[路由模块](../../SLAC/retrieval/routing/README.md)提供固定折分、显式训练域、不可变模型、单独预测和配额选择接口。训练 API 拒绝多余的测试目标；交叉验证协调函数与推理入口分开。默认检索策略没有替换。

四特征策略在逻辑上跳过 40 个问题、631 个候选支持判断，但这些是缓存回放计数，不能换算成 HTTP 请求数、美元或延迟节省。路由前还需要 BGE 分数及 Dense/BGE 包；本阶段没有测量部署时这些步骤的成本。所有新计算均为本地特征处理和小规模线性代数。

## 研究决定

不继续在相同结果上调试这四个特征，不把普通路由或“换成 JEV”宣称为创新。下一步先检查现有缓存能否提供严格的证据集合对照，例如只增加一个单元的嵌套包或完整二乘二集合组合。这仅检查映射和覆盖，在可行性明确、问题与判据另行冻结前，不查看有利质量差来挑对照，也不发起新的模型调用。

随后完成的纯映射盘点发现：454 个共同池内缓存包覆盖原 77 题；32 条严格单元添加对照覆盖 22 题、15 个 family，但完整二乘二组合为零。因此下一项[缓存添加诊断](NEXT_CACHED_ADDITION_DIAGNOSIS_20261004.md)仅研究条件性的单元添加敏感性，不能估计二阶交互或推出完整新方法的 Answer F1。该诊断尚未执行。

In this paper we have introduced the notion of weak reduced module and weak rigid module as the generalizations of reduced module by working on the context of nilpotent elements of module and investigated some of its properties. Various results are extended for this generalization and some counter examples are constructed to validate the generalizations.

Introduction

A ring R is reduced if the set of nilpotent elements of R ( i.e. nil(R)) contains only the zero element or whenever a 2 = 0 implies a = 0 for a ∈ R. A ring R is called rigid whenever a 2 b = 0 implies that ab = 0 for all a,b ∈ R. Reduced rings are always rigid. Both are same in the situation when the ring is with identity. In [1], [2] and [3] they introduced new classification of reduced ring and rigid rings on the basis of set of central elements C(R) of R, the set of nilpotent elements nil(R) of R and rigid endomorphism (in [4]). Again the concept of reduced ring was extended to R-module by T.Lee and Y.Zhou in [5]. They called a left R-module a reduced module if a ∈ R and m ∈ M satisfying a 2 m = 0 implies aRm = 0. Easily we can check that R is reduced ring iff R R is reduced module. Similarly a left R-module M is rigid if for a ∈ R and m ∈ M , a 2 m = 0 implies am = 0. Therefore rigid module is a generalization of reduced module itself. In [6] [7]. Recently Ssevviiri and Groenewald introduced the concept of nilpotent element for module in [8]. In this paper the term "weak" is used to generalize the reduced module and rigid module on the basis of the definition of nilpotent element of a module IOP Publishing doi:10.1088/1757-899X/1020/1/012024 2 as defined in [8]. The properties of reduced and rigid modules are extended using this new generalizations and constructed counter examples in some cases.


The nilpotent elements in a module

In [8], the definition of a nilpotent element of a module R M is given as :

A non zero element m of M is called a nilpotent element if ∃ r ∈ R and a natural number k > 1 such that r k m = 0 but rm = 0. Here k is said to be the degree of nilpotency of m. The zero element of M is always considered as a nilpotent element. The set of nilpotent elements of M is denoted as nil R (M ).

Weak reduced module and weak rigid module

We start with the following definitions and some of their basic properties: 


Definition

A module R M is weak reduced module if whenever a 2 m = 0 for a in R and m in M implies aRm ⊆ nil R (M ).


Definition
A module R M is weak rigid module if whenever a 2 m = 0 for a in R and m in M implies am ∈ nil R (M ).
The direct results from the above definitions:

(i) Every reduced module (respectively rigid module) is a weak reduced module (respectively weak rigid module). (ii) Every weak reduced module is weak rigid module. (iii) Every reduced module is weak rigid module. (iv) Submodules of a weak reduced module (respectively weak rigid module) are weak reduced modules (respectively weak rigid modules).

Conclusion

In this paper the study introduced weak reduced module (3.1) and weak rigid module (3.2), which generalized the concept of reduced module and rigid module respectively. Moreover weak rigid module is itself a generalization of weak reduced module and it is emphasized by the constructed example given in 3.13.1. Finally a number of properties of these generalizations are investigated here.


Throughout this paper R denotes an associative ring with identity and M is unitary left R−module (denoted as R M ). Some terms like T or(M ), ann(M ), ann(m), M n (R) and T n (R) are used here. T or(M ) is defined as T or(M ) = {m ∈ M : rm = 0, if ∃r( = 0) ∈ R} and it forms a submodule of M if the ring R is commutative domain. The set ann(M ) = {r ∈ R : rm = 0, ∀m ∈ M } forms a left ideal and ann(m) = {r ∈ R : rm = 0}. M n (R) is the set of all matrices of order n over R, where T n (R) is the set of all upper triangular matrices of order n over R and it has ring structure with respect to the usual matrix addition and multiplication.

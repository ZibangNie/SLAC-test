The notions of bounded-size and quasibounded-size decompositions with bounded treedepth base classes are central to the structural theory of graph sparsity introduced by two of the authors years ago, and provide a characterization of both classes with bounded expansions and nowhere dense classes.Strong connections of this theory with model theory led to considering first-order transductions, which are logically defined graph transformations, and to initiate a comparative study of combinatorial and model theoretical properties of graph classes, with an emphasis on the model theoretical notions of dependence (or NIP) and stability.In this paper, we first prove that the model theoretic notions of dependence and stability are, for hereditary classes of graphs, compatible with quasibounded-size decompositions, in the following sense: every hereditary class with quasibounded-size decompositions with dependent (resp.stable) base classes is itself dependent (resp.stable).This result is obtained in a more general study of "decomposition horizons", which are class properties compatible with quasibounded-size decompositions.We deduce that hereditary classes with quasibounded-size decompositions with bounded shrubdepth base classes are stable.In the second part of the paper, we prove the converse.Thus, we characterize stable hereditary classes of graphs as those hereditary classes that admit quasiboundedsize decompositions with bounded shrubdepth base classes.This result is obtained by proving that every hereditary stable class of graphs admits almost nowhere dense quasi-bush representations, thus answering positively a conjecture of Dreier et al.These results have several consequences.For example, we show that every graph G in a stable, hereditary class of graphs C has a clique or a stable set of size Ω C ,ε (|G| 1/2−ε ), for every ε > 0, which is tight in the sense that it cannot be improved to Ω C (|G| 1/2 ).

Introduction

Initiated in 2005, the structural theory of graph sparsity [34] aims to provide a general framework for the study of monotone classes of sparse graphs based on the notion of shallow minors.The notion of shallow minors was proposed by Leiserson and Toledo, and initially used by Plotkin, Rao, and Smith in their study of vertex separators [40].Recall that a class of graphs is monotone if every subgraph of a graph in the class also belongs to the class, and that a depth-r minor of a graph G is a graph that can be obtained from G by contracting vertex-disjoint subgraphs with radius at most r and deleting some vertices and edges.

The notions of a class with bounded expansion [29] and of a nowhere dense class [31] are defined in terms of shallow minors: they are those classes of graphs whose depth-r minors have average degree (resp.clique number) bounded by a function of r (see formal definitions in Section 2).Note that these properties are preserved by taking subgraphs.Hence, a class C has bounded expansion (resp. is nowhere dense) if and only if the same holds for the monotone closure of C (that is, for the class of all the subgraphs of graphs in C ).Some fundamental structural and algorithmic properties of these graph classes have been obtained using special decompositions, the so-called low treedepth decompositions (also called low treedepth colorings) 1 [30,33,35].

As a generalization of these decompositions is central to this paper, we take time for introducing some definitions and terminology.A class property Π is a set of graph classes that is closed by subclasses (i.e., if C ∈ Π and D ⊆ C , then D ∈ Π).For instance, "(being) degenerate", "excluding a minor", and "(having) bounded maximum degree" are class properties.For a function f : N → N and a parameter p, a class of graphs C has an f -bounded Π-decomposition with parameter p if there exists a graph class D p ∈ Π, such that every graph G ∈ C has a vertex coloring by f (|G|) colors with the property that every p color classes induce a subgraph in D p .In this paper, we will consider only infinite classes of graphs and will be mainly interested in the asymptotic behavior of bounding functions.Particularly, we say that a class C has bounded-size decompositions (resp.quasiboundedsize decompositions) if, for every integer p, it has an f p -bounded Π-decomposition with parameter p, where f p (n) ∈ O(1) (resp.f p (n) ∈ O(n ε ) for every ε > 0).Using this terminology, we have the following characterization theorems, based on the class property "bounded treedepth" (see Section 2.1 for a definition of treedepth).

▶ Theorem 1 ([27, 29]).A class C has bounded expansion if and only if it has bounded-size bounded treedepth decompositions.


▶ Theorem 2 ([33]). A hereditary class C is nowhere dense if and only if it has quasiboundedsize bounded treedepth decompositions.

Classes with bounded expansion and nowhere dense classes have strong algorithmic properties related to first-order logic [12,20], and it was conjectured that such a connection was ultimately due to the fact that, for monotone classes of graphs, nowhere denseness is equivalent to the model theoretic notions of dependence and stability (as well as to their monadic versions) [1]; see Section 2.2 for a formal definition of these model theoretical notions.

▶ Theorem 3 ([1]).For a monotone class of graphs C , the following are equivalent:

C is nowhere dense; C is stable; C is dependent; C is monadically stable; C is monadically dependent.

On the one hand, the notions of stability and dependence are central combinatorial properties in model theory, which delimit strong dividing lines between "tame" and "wild" theories.On the other hand, the model theoretical notions of interpretations and transductions (see Section 2.3) suggested the possibility to study structural properties of graph classes, whose members are (uniformly) defined from a class of sparse graphs by using logical formulas.Unfortunately, stability and dependence are not in general preserved by transductions, while their monadic versions are.However, the collapse of these notions for monotone classes (as it appears in Theorem 3) partially extends to hereditary classes.


▶ Theorem 4 ([4]). A hereditary class of graphs C is monadically dependent if and only if it is dependent; it is monadically stable if and only if it is stable.

This will allow us to interchangeably use "stable" and "monadically stable" and similarly "dependent" and "monadically dependent" when we speak about hereditary classes of graphs.

The notion of transduction led to the graph-theoretical concept of structural sparsity [36].For instance, classes with bounded shrubdepth, which are defined by the existence of very specific tree models 2 , are characterized as those classes of graphs that are transductions of classes of bounded diameter trees [17].They are a natural dense analog of classes with bounded treedepth, as witnessed by their characterization as those classes of graphs having bounded SC-depth [17] (see definition of SC-depth in Section 4.2).Classes with structurally bounded expansion (i.e., transductions of classes with bounded expansion) have been characterized in terms of bounded-size decompositions.


▶ Theorem 5 ([15]). A class of graphs C has structurally bounded expansion if and only if it has bounded-size bounded shrubdepth decompositions.

Then, it has been conjectured that a similar characterization exists for structurally nowhere dense classes, that is, for transductions of nowhere dense classes.▶ Conjecture 6.A hereditary class of graphs C is structurally nowhere dense if and only if it has quasibounded-size bounded shrubdepth decompositions.

However, the only published conjectures we have found mention only the left-to-right implication [23] (see also [7,10]), which has been proved recently.

▶ Theorem 7 ([10]).Every structurally nowhere dense class of graphs has quasibounded-size bounded shrubdepth decompositions.

On the other hand, a natural extension of Theorem 3 to hereditary classes was conjectured.

▶ Conjecture 8 ([37, Conjecture 6.1]).A hereditary class of graphs C is structurally nowhere dense if and only if it is (monadically) stable.

Note that the left-to-right implication follows from Theorem 3, as every structurally nowhere dense class is a transduction of a (monotone) nowhere dense class, and monadic stability is preserved under transductions.

Together with Conjectures 6 and 8, it is natural to consider the following conjecture.

▶ Conjecture 9. A hereditary class of graphs C is stable if and only if it has quasibounded-size bounded shrubdepth decompositions.

Indeed, any two of the Conjectures 6, 8, and 9 imply the third.


Our Results

In this paper we give a new characterization of hereditary stable classes that confirms Conjecture 9.


▶ Theorem 10. A hereditary class of graphs C is stable if and only if it has quasibounded-size bounded shrubdepth decompositions.

It may seem surprising at a first glance that general hereditary stable classes can be characterized in terms of decompositions into classes as restricted as classes with bounded shrubdepth.This result is achieved by a combination of various recently introduced techniques (see in particular [10,9]) together with a new general study of bounded-size and quasiboundedsize Π-decompositions, which we present in Section 3. In this section, we focus particularly on class properties Π so that every hereditary class with quasibounded-size Π-decompositions actually belongs to Π.We call such class properties decomposition horizons, and we provide some examples of them, notably: ▶ Theorem 11.The class properties "dependent" and "stable" are decomposition horizons.In particular, hereditary classes with quasibounded-size bounded shrubdepth decompositions are stable.

The left-to-right implication of Theorem 10 is an extension of Theorem 7 based on a strengthening of the notion of neighborhood covers (see Section 4).Some consequences of Theorem 10 are discussed in Section 5.In particular, we show that it follows from Theorem 10 that every graph G in a stable, hereditary class of graphs C contains a clique or a stable set of size Ω C ,ε (|G| 1/2−ε ) (for every ε > 0).This paper is an extended version of the abstract Decomposition horizons: from graph sparsity to model-theoretic dividing lines [6] presented at Eurocomb 2023.The main result of this paper, Theorem 10, as well as the results in Sections 4 and 5 are new.


Preliminaries

We assume basic familiarity with first-order logic and graph theory, and refer e.g. to [21,8] for background and for all undefined notation.All graphs considered here are undirected.


Basic graph theory

The vertex set of a graph G is denoted as V (G) and its edge set as E(G).
G[A] = G[A, A] and that G[A, B] is bipartite if A and B are disjoint.
For a graph G and an integer p, the pth subdivision G (p) of G is the graph obtained by replacing each edge of G by a path of length p + 1.For two graphs G and H, we denote by G + H the disjoint union of G and H.

A class of graphs C is monotone (resp.hereditary) if every subgraph (resp.induced subgraph) of a graph in C also belongs to C .Classes with bounded expansion and nowhere dense classes may be defined in several equivalent ways (see [34]).The original definition is in terms of shallow minors.The radius of a connected graph G is the minimum integer r such that there exists a vertex v ∈ V (G) at distance at most r from all the other vertices of G.A graph H is a depth-r minor of a graph G if there exists a mapping η that maps vertices of H to pairwise disjoint subgraphs of G, such that for each u ∈ V (U ), η(u) is connected and has radius at most r, for each edge uv of H, there is an edge of G with one incidence in η(u) and one incidence in η(v).

A graph H is a depth-r topological minor of G if there exists an injective mapping ν : V (H) → V (G) and a family P of internally vertex-disjoint paths of G with length at most 2r + 1 (with internal vertices not in the image of ν), such that for every edge uv ∈ E(H) there is a path P uv ∈ P with endpoints ν(u) and ν(v).A class C is nowhere dense if, for every integer r, the clique number of the depth-r minors of the graphs in C is bounded by a constant C(r); it has bounded expansion if, for every integer r, the average degree of the depth-r minors of the graphs in C is bounded by a constant D(r).

In this paper, it will be convenient to use the following characteristic properties (cf.[34]).A class C has bounded expansion if there exists a function f : N → N with the following property: if H is a graph with the property that H (p) is a subgraph of a graph in C , then the average degree of H is at most f (p).A class C is nowhere dense if there exists a function f : N → N with the following property: if H is a graph with the property that H (p) is a subgraph of a graph in C , then the clique number of H is at most f (p).

We denote by ∇ r (G) the rank-r greatest average density of G, that is, the maximum edge density of the depth-r minors of G:
∇ r (G) = max |E(H)| |V (H)| : H is a depth-r minor of G .
Similarly, we denote by ∇ r (G) the rank-r topological greatest average density of G, that is, the maximum edge density of the depth-r topological minors of G:
∇ r (G) = max |E(H)| |V (H)| : H is a depth-r topological minor of G .
It is clear from the definition that a class has bounded expansion if ∇ r (G) ∈ O C ,r (1) holds for graphs G ∈ C .It is known [34] that this is equivalent to ∇ r (G) ∈ O C ,r (1).We can also use the greatest average densities to characterize nowhere-denseness.

▶ Theorem 12 ([33]).For a hereditary class C of graphs, the following are equivalent:
1. C is nowhere dense; 2. ∇ r (G) ∈ O C ,r,ε (|G| ε ), for every r ∈ N, every ε > 0, and graph G ∈ C . 3. ∇ r (G) ∈ O C ,r,ε (|G| ε ), for every r ∈ N, every ε > 0, and graph G ∈ C .
Recently, a weakening of the notion of nowhere-denseness has been proposed, in terms of bounding of weak coloring numbers [10].As weak coloring numbers are polynomially equivalent to the greatest average densities, we can reformulate the definition as follows: A class of graphs C is almost nowhere dense if ∇ r (G) ∈ O C ,r,ε (|G| ε ), for every r ∈ N and every ε > 0 or, equivalently, ∇ r (G) ∈ O C ,r,ε (|G| ε ), for every r ∈ N and every ε > 0. Note that an almost nowhere dense class is not assumed to be hereditary, and that a hereditary almost nowhere dense class is nowhere dense.

The treedepth of a graph is a minor montone graph invariant that has been defined in [28], and is defined as the minimum height of a rooted forest Y such that G is a subgraph of the closure of Y (that is, of the graph obtained by adding edges between a vertex and all its ancestors).The treedepth of a graph G can be defined inductively by td(K 1 ) = 1, td(G + H) = max(td(G), td(H)), and td(G
) = 1 + min v∈V (G) td(G − v) if G is connected and G ̸ ≃ K 1 .

Basic model theory

In this paper we consider either graphs or σ-expanded graphs, that is, graphs with additional unary relations in σ (for a set σ of unary relation symbols).In particular, a σ-expanded graph obtained by adding to a graph G additional unary relations in σ will be called a σ-expansion of G.We usually denote graphs by G, H, . . .and σ-expanded graphs by G + , H + , G * , H * , . .., but sometimes we will use G, H, . . .for σ-expanded graphs as well.We shall often use the term "colored graph" instead of σ-expanded graph.By extension, a σ-expansion of a class C is a class containing, for each G ∈ C , a σ-expansion of G.In formulas, the adjacency relation will be denoted as E(x, y).Whenever we speak of formulas we will mean first-order formulas.For a formula φ(x) and a (colored) graph G, we denote by φ(G) the set all tuples v ∈ V (G) |x| such that G satisfies φ(v).

We recall some classical model-theoretical notions due to Shelah.

A class C is unstable if there exists a formula φ(x, ȳ) such that, for every n ∈ N there exist a graph G ∈ C and 2n tuples of vertices ū1 , . . ., ūn ∈ V (G) |x| and v1 , . . ., vn ∈ V (G) |ȳ| with
G |= φ(ū i , vj ) ⇐⇒ i ≤ j. If C is not unstable, then it is stable. C is monadically stable if every σ-expansion of C is stable.
A class C is independent if there exists a formula φ(x, ȳ) such that, for every n ∈ N there exist a graph G ∈ C and n + 2 n tuples of vertices ūi
∈ V (G) |x| (i ∈ [n]) and vJ ∈ V (G) |ȳ| (J ⊆ [n]) with G |= φ(ū i , vJ ) ⇐⇒ i ∈ J.
If C is not independent, then it is dependent (or NIP).C is monadically dependent if every σ-expansion of C is dependent.


Transductions

For a set σ of unary relations, the coloring operation Γ σ maps a graph G to the set Γ σ (G) of all its σ-expansions.

A simple interpretation I of graphs in σ-expanded graphs is a pair (ν(x), η(x, y)) consisting of two formulas (in the first-order language of σ-expanded graphs), where η is symmetric and anti-reflexive (i.e., |= η(x, y) ↔ η(y, x) and |= η(x, y)
→ ¬(x = y)). If G + is a σ-expanded graph, then H = I(G + ) is the graph with vertex set V (H) = ν(G + ) and edge set E(H) = η(G + ) ∩ ν(G + ) 2 .
A transduction3 T is the composition I • Γ σ of a coloring operation Γ σ and a simple interpretation I of graphs in σ-expanded graphs.In other words, for every graph G we have T(G) = {I(H + ) : H + ∈ Γ σ (G)}.We denote by Id the identity transduction, which is such that Id(A) = {A} for every structure A. The transduction T is quantifier-free if all the formulas defining the interpretation part of T are quantifier-free.A subset complementation transduction is defined by the quantifier-free interpretation on a σ-expansion (with σ = {M }) by η(x, y) := (x ̸ = y) ∧ ¬ E(x, y) ↔ (M (x) ∧ M (y) .In other words, the subset complementation transduction complements the adjacency inside the subset of the vertex set defined by M .We denote by ⊕ M the subset complementation defined by the unary relation M .A perturbation is a composition of (a bounded number of) subset complementations.For a class D and a transduction T we define T(D) = G∈D T(G) and we say that a class
C is a T-transduction of D if C ⊆ T(D).
Transductions allow for an alternative characterization of monadic stability and monadic dependence, using results of [2].We first recall that the half-graph of length n is the bipartite graph with vertices
{a i , b i : i ∈ [n]} such that E(a i , b j ) ⇐⇒ i ≤ j.

▶ Proposition 13. A class C is monadically dependent if and only if it does not transduce the class of all finite graphs.

A class C is monadically stable if and only if it does not transduce the class of all finite half-graphs.

Transductions are at the heart of the definition of shrubdepth, which is a measure of the structural complexity of graph classes (and not of single graphs).A class D has shrubdepth at most d if it is a transduction of a class of forests with radius at most d [17].A more combinatorial characterization of bounded shrubdepth classes, in terms of SC-depth, reflects the proximity to cographs (see Section 4.2).

Decomposition horizons


Π-decompositions

Decompositions aim to break complex graphs into simpler ones.In this section, we generalize the decompositions used in Theorem 1 and Theorem 2 and establish some of their abstract properties.We define a hereditary class property to be a downset Π of hereditary graph classes, that is, a set of hereditary classes such that if C ∈ Π and D is a hereditary class with D ⊆ C , then D ∈ Π.

▶ Definition 14.Let Π be a hereditary class property, let f : N → N be a non-decreasing function and let p be a positive integer.We say that a class C has an f -bounded Π-decomposition with parameter p if there exists D p ∈ Π such that, for every graph G ∈ C , there exists an integer
N ≤ f (|G|) and a partition V 1 , . . . , V N of the vertex set of G with G[V i1 ∪ • • • ∪ V ip ] ∈ D p for all i 1 , . . . , i p ∈ [N ].
When f is a bounded function, we say that C has a bounded-size Π-decomposition with parameter p; when f is a function with f (n) = O ε (n ε ) for every ε > 0, we say that C has a quasibounded-size Π-decomposition with parameter p.If a class C has a bounded-size (resp.a quasibounded-size) Π-decomposition with parameter p for each positive integer p, we say that C has bounded-size Π-decompositions (resp.quasibounded-size Π-decompositions).

For instance, by Theorem 1 and Theorem 2, considering the hereditary class property "bounded treedepth", we have that a class C has bounded-size bounded treedepth decompositions if and only if it has bounded expansion, and it has quasibounded-size bounded treedepth decompositions if and only if it is nowhere dense.

We can interpret these definitions as operators, constructing a (possibly larger) class property by the existence of special decompositions into a given base class property.This can be formulated as follows:

▶ Definition 15.For a hereditary class property Π we define the properties Π + (resp.Π * ) as follows:
C ∈ Π + if C has bounded-size Π-decompositions; C ∈ Π * if C has quasibounded-size Π-decompositions.
In this notation, for Π = 'bounded treepdepth', we have Π + = 'bounded expansion' and Π * = 'nowhere dense'.

Decompositions of hereditary stable classes

The aim of this section is to introduce all the techniques and results needed to prove Theorem 10 in Section 5, that is, that a hereditary class of graphs is stable if and only if it has quasibounded-size bounded shrubdepth decompositions.The first tool is the use of neighborhood covers, which allows us to restrict the study to graphs with bounded diameters.The second is the use of flipping, which is central to the characterization of monadically stable class by the so-called Flipper game.This offers a way to decompose the graphs in a monadically stable class with a bounded depth recursion.Such a decomposition is given by the so-called quasi-bush representations, which are in spirit very close to the quasi-bounded size bounded shrubdepth decompositions we are aiming for.


Neighborhood covers

The notion of (sparse) neighborhood covers was used in [20] to design a quasi-linear time algorithm for first-order model checking on nowhere dense classes.The existence of sparse neighborhood covers on monotone classes is strongly related to bounding of weak coloring numbers [19].Let us recall the definitions.

The weak diameter of a subset X of vertices of a graph G is the maximum distance in G between vertices in X.The strong diameter of X is the diameter of G[X] (and ∞ if G[X] is not connected).Let G be a graph and r be a positive integer.The (closed) r-neighborhood N r G [v] of a vertex v in G is the set of all the vertices at distance at most r from v in G.The r-ball of G centered at v, denoted B r (G, v), is the subgraph of G induced by all the vertices at distance at most r from
v: B r (G, v) = G[N r G [v]]. More generally, if X is a subset of vertices of G, we define N r G [X] = v∈X N r G [v] and B r (G, X) = G[N r G [X]
].Note that B r (G, X) does not need to be connected in general.

A family K of subsets of V (G) is a distance-r neighborhood cover of G if, for every v ∈ V (G), the r-neighborhood of v in G is included in some C ∈ K .We define the weak (strong) diameter of K as the maximum weak (strong) diameter of the sets in K , and the overlap of K as the maximum number of sets in K a vertex of G belongs to: overlap(K ) := max u∈V (G) {C ∈ K : u ∈ C} .Following [9], for a graph G we call a subset
X of V (G) compact if there exists a vertex u of G with X ⊆ N G [u]. A partition Z of the vertex set of G is called compact if every element of Z is compact. A distance-1 neighborhood cover K is compact if there exists a compact partition Z of V (G) with K = {N G [Z] : Z ∈ Z }. The incidence graph of a neighborhood cover K of a graph G is the bipartite graph Inc(K ) = (K , V (G), F ), where C ∈ K is adjacent to v ∈ V (G), that is, {C, v} ∈ F , if v ∈ C. Note that if r ≤ r ′ , every distance-r ′ neighborhood cover of G is also a distance-r neighborhood cover of G.
The existence of sparse neighborhood covers with small overlap can be used to characterize those monotone classes of graphs that have bounded expansion or are nowhere dense.

Quasi-bush representations

The computation of quasibounded-size bounded shrubdepth decompositions for monadically stable classes of graphs will be based on quasi-bush representations, which were introduced in [10].A quasi-bush is a binary structure consisting of a bounded height rooted tree Y , a set D of directed edges (called pointers) from the leaves of Y to internal nodes of Y , a labeling function λ, from the leaves of Y to a finite set Λ and a labeling function λ D from D to the power set of Λ.A quasi-bush B encodes a graph G(B) whose vertex set is the set of leaves of Y as follows: a vertex u is adjacent to a vertex v if there exists a pointer (u, z) from u to an ancestor z of v in the tree, such that z is the lowest ancestor of v such that (u, z) is a pointer; the label of v belongs to the label of (u, z), that is:
λ(v) ∈ λ D (u, z).
In this paper, instead of giving a label λ(v) to a vertex v and a label λ D (e) to an arc e, we associate to both a binary vector (b(v) and b(e), respectively) and replace the condition λ(v) ∈ λ D (e) by the condition ⟨b(v), b(e)⟩ = 1.

In [9] it was proved that every structurally nowhere dense class admits almost nowhere dense quasi-bush representations, and the following conjecture was proposed.

▶ Conjecture 57 ([9,Conjecture 4]).For every monadically stable class of graphs C , there is an almost nowhere dense class B of quasi-bushes that encode graphs from C .

In this section, we prove this conjecture.The construction of a quasi-bush representation will be based on two ingredients: induced neighborhood covers and the Frank r invariants.It will consist of two steps: the construction of a decomposition tree, and the definition of the pointers.

Erdős-Hajnal property

A hereditary class of graphs C has the Erdős-Hajnal property if there exists a constant c >0 such that every graph G ∈ C has a clique or independent set of size Ω C (|G| c ).The celebrated Erdős-Hajnal conjecture asserts that for every fixed graph H, the class of all graphs with no induced subgraph isomorphic to H has the Erdős-Hajnal property.It has been proved recently [39] that every hereditary class of graphs with bounded VC-dimension (hence, every hereditary dependent class) has the Erdős-Hajnal property.Malliaris and Shelah implicitly proved [26] that hereditary classes of graphs with stable edge relation have the Erdős-Hajnal property by developing regularity lemmas for these graphs.However, the derived exponent depends on the size of the largest half-graph present in the graphs of the class.We prove that under the stronger assumption of stability, the exponent can be taken arbitrarily close to 1/2.Following [18], denote by c(G) the c-chromatic number of a graph G, that is, the minimum size of a partition of the vertex set of G such that each part induces a cograph.As every cograph G has a clique or independent set with size |G| 1/2 , we immediately infer that for every graph G we have
max(α(G), ω(G)) ≥ c(G) −1/2 |G| 1/2 .
▶ Remark 61.For instance, as the c-chromatic number of a graph is bounded by a function of its linear clique-width [38], there is a function f : N → (0, 1] such that every graph G with linear clique-width t has a clique or an independent set of size f (t) |G| 1/2 .

As every class of graphs with bounded shrubdepth has bounded c-chromatic number (see [38]) we get that every hereditary class C with quasibounded-size bounded shrubdepth decompositions (at least for parameter 1) has the Erdős-Hajnal property with exponent 1/2 − ε, for every ε > 0. Discussion

We have proved that several hereditary graph properties are decomposition horizons.We have chosen to give direct proofs for some of them where we instead could have used Corollary 19 and later results.

For instance: "nowhere dense" is a decomposition horizon, as it is the intersection of the decomposition horizons "stable" and "weakly sparse"; "bounded maximum degree after deletion of a bounded number of vertices" is a decomposition horizon, as it is the intersection of "transduction of a class with bounded degree" and weakly sparse.

Also, we would like to stress that general properties of decomposition horizons and "dependent" and "stable" are decomposition horizons hold in the more general setting of relational structures.

Our examples include an infinite countable chain of decomposition horizons (Corollary 29), witnessing some richness of the inclusion order of decomposition horizons.Note that this order is a distributive lattice (by Corollary 19 and Lemma 20).

We now consider few problems naturally arising from our study.

In our study of decomposition horizons, we have introduced the operators Π → Π + and Π → Π * .While the former is clearly idempotent (cf.Corollary 17), it is not clear whether the latter is.

▶ Problem 1.Is there a hereditary (dependent) class property Π such that Π * ̸ = (Π * ) * ?Also, we have seen that the operators Π → Π + and Π → Π * preserve finite intersections (Corollary 19).This suggests the next problem.

▶ Problem 2. Is it true that for every hereditary class property Π there is an inclusionminimum hereditary class property Λ with Λ + = Π + ?The same problem can be asked for Λ * = Π * .

We will say that a hereditary class property Π is minimal if there is no smaller hereditary class property Λ with Λ + = Π + or Λ * = Π * .It is easily seen that for all integers n, k, h, c there exists a c-colored forest with height h with (nkc) h vertices such that in every partition of the vertex set into k parts and every c-colored forest F with height at most h, some copy of F is included within c parts.From this it follows that the hereditary class properties "bounded treedepth" and "bounded shrubdepth" are minimal.Hence, for every hereditary class property Π, we have the following equivalences.

"bounded treedepth" ⊆ Π ⊆ "bounded expansion" ⇐⇒ Π + = "bounded expansion" "bounded treedepth" ⊆ Π ⊆ "nowhere dense" ⇐⇒ Π * = "nowhere dense" "bounded shrubdepth" ⊆ Π ⊆ "structurally bounded expansion" ⇐⇒ Π + = "structurally bounded expansion" "bounded shrubdepth" ⊆ Π ⊆ "stable" ⇐⇒ Π * = "stable"

While stable hereditary classes of graphs are exactly those hereditary classes with quasibounded-size bounded shrub-depth decompositions, dependent hereditary classes seem to be more elusive.It was proved in [3] that for hereditary classes of ordered graphs, being dependent is equivalent to having bounded twin-width.On the other hand, classes with quasibounded-size bounded twin-width decompositions are dependent (as classes with bounded twin-width are dependent) and include all stable hereditary classes.This suggests the following problem.

▶ Problem 3. Is the class property "dependent" the decomposition horizon of the class property "bounded twin-width"?More generally, what is the smallest class property Π such that every hereditary dependent class has a quasibounded Π-decomposition (assuming such a minimal class exists, cf.Problem 2)?

We remark that "bounded linear cliquewidth" is a too strong class property to have "dependent" as its decomposition horizon, as even classes with bounded cliquewidth do not have, in general, quasibounded-size bounded linear cliquewidth decompositions (even with parameter 1).Indeed, every hereditary class C with quasibounded-size bounded linear cliquewidth decompositions has the Erdős-Hajnal property with exponent 1/2 (see Remark 61).On the other hand, the hereditary closure of the lexicographic powers of C 5 has bounded cliquewidth but the graph G = C •n 5 (which belongs to C ) has no homogeneous set of size greater than |G| log 2/ log 5 < |G| 0.41 .(Note that a similar argument shows that there is no constant β > 0 such that for every class C with bounded cliquewidth every graph G in C has an independent set or a clique of size Ω C (|G| β ).)

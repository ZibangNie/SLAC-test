Universal Metric Spaces According to W. Holsztynski
13 Apr 2000 October 27, 2018arXiv:math/0004091v1 [math.GN]
In this note we show, following W. Holsztynski, that there is a continuous metric d on R such that any finite metric space is isometrically embeddable into (R, d).

Let M be a family of metric spaces. A metric space U is said to be a universal space for M if any space from M is (isometrically) embeddable in U .

Fréchet [2] proved that ℓ ∞ (the space of all bounded sequences of real numbers endowed with the sup norm) is a universal space for the family M of all separable metric spaces. Later, Uryson [5] constructed an example of a separable universal space for this M (ℓ ∞ is not separable).

In this note we establish the following result which is Theorem 5 in [3].
Theorem 1.
There exists a metric d in R, inducing the usual topology, such that every finite metric space embeds in (R, d).

Our proof essentially follows the original Holsztynski's approach [4]. We say that a metric space (X, d) is ε-dispersed if d(x, y) ≥ ε for all x = y in X (ε > 0). Clearly, any ε-metric space is also ε ′ -dispersed for any positive ε ′ < ε. The following proposition will be used to construct universal spaces for particular families M.
Proposition 1. Let f : X → Y be a continuous surjection from a metric space (X, d) onto a metric space (Y, D). Then (X, d ε ) where d ε (x, y) = max{min{d(x, y), ε}, D(f (x), f (y))} (1)
is a universal space for the family of ε-dispersed subspaces of (Y, D) and metrics d and d ε are equivalent on X.

Proof. d ε is a distance function. Indeed, d ε is symmetric and d ε (x, y) = 0 if and only if x = y. We have
max{ min{d(x, y), ε}, D(f (x), f (y))} + max{min{d(y, z), ε}, D(f (y), f (z))} ≥ ≥ D(f (x), f (y)) + D(f (y), f (z)) ≥ D(f (x), f (z)) and max{ min{d(x, y), ε}, D(f (x), f (y))} + max{min{d(y, z), ε}, D(f (y), f (z))} ≥ ≥ min{d(x, y), ε} + min{d(y, z), ε} = min{d(x, y) + d(y, z), ε} ≥ ≥ min{d(x, z), ε} Hence, d ε (x, y) + d ε (y, z) ≥ d ε (x, z). Let Z be an ε-dispersed subspace of Y . Since f is surjective, for any z ∈ Z, there is x z ∈ X such that f (x z ) = z. Let X ′ = {x z : z ∈ Z}. By (1), d ε (x, y) = D(f (x), f (y))
for all x, y ∈ X ′ . Thus f establishes an isometry between (Z, D) and (X ′ , d ε ).

In what follows, M is the family of all finite metric spaces. We define
I n = {x = (x 1 , . . . , x n ) ∈ R n : 0 ≤ x i ≤ n, 1 ≤ i ≤ n}
and J n = [n − 1, n] for n ≥ 1. I n is a metric space with the distance function
D(x,ȳ) = max{|x i − y i | : 1 ≤ i ≤ n},
and J n is a metric space with the usual distance.

Let f n be a continuous surjection from J n onto I n (a "Peano curve" [1, IV(4)]) and d n (x, y) be the distance function on J n defined by (1) for ε = 1 n . Note, that d n is equivalent to the usual distance on J n . By Proposition 1, J n is a universal space for any 1 n -dispersed subspace of I n . By Proposition 2, any finite metric space is embeddable in (J n , d n ) for some n.

It is easy to show that there is a continuous distance function on R that coincides with d n (x, y) on J n for all n. Indeed, let d 1 (x, y) and d 2 (x, y) be two continuous distance functions on intervals [a, b] and [b, c], respectively. Then d(x, y) defined by
d(x, y) =      d 1 (x, y), if x, y ∈ [a, b], d 2 (x, y), if x, y ∈ [b, c], d 1 (x, b) + d 2 (b, y), if x ∈ [a, b] and y ∈ [c, d].
is a continuous distance function on [a, c]. In fact, thus defined d is equivalent to the usual metric on [a, c].

By applying this process consecutively, we obtain a required distance function on R.

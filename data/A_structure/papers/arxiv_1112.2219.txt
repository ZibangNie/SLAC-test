SINGULARITIES OF PLURI-THETA DIVISORS IN CHAR p > 0
9 Dec 2011

Christopher D Hacon 
SINGULARITIES OF PLURI-THETA DIVISORS IN CHAR p > 0
9 Dec 2011
We show that if (X, Θ) is a PPAV over an algebraically closed field of characteristic p > 0 and D ∈ |mΘ|, then (X, 1 m D) is a limit of strongly F -regular pairs and in particular mult x (D) ≤ m · dim X for any x ∈ X.

introduction

Let (X, Θ) be a principally polarized abelian variety (PPAV) so that X is a connected projective algebraic group and Θ is an ample divisor with h 0 (X, O X (Θ)) = 1. The geometry of X is often studied in terms of the singularities of the theta divisor Θ (or more genereally of the singularities of pluri-theta divisors i.e. divisors in |mΘ|). For PPAVs over C there are a number of well known results saying that the singularities of pluri-theta divisors are mild (see for example [Kollar95], [EL97] and [Hacon99]). According to a result of Ein and Lazarsfeld (cf. [EL97,3.5]), if D ∈ |mΘ|, then (X, 1 m D) is log canonical. Since X is smooth, this is equivalent to saying that (X, 1−ǫ m D) is Kawamata log terminal for any 0 < ǫ < 1. The purpose of this brief note it to prove the analogous result in characteristic p > 0.

Theorem 1.1. Let (X, Θ) be a PPAV over an algebraically closed field of characteristic p > 0. If D ∈ |mΘ|, then (X, 1−ǫ m D) is strongly Fregular for any rational number 0 < ǫ < 1.

Remark 1.2. In particular it follows that (X, 1 m D) is log canonical in the sense that all log-discrepancies are ≥ 0 and therefore mult x (D) ≤ m · dim X for any x ∈ X. Note that in characteristic 0 it is known that if mult x (D) = m · dim X, then X is a product of elliptic curves [EL97] and [Hacon99]. We do not know if the analogous result holds in characteristic p > 0. By [Hernandez11,4.1] it follows that (X, D) is F -pure, and if p and m are coprime, then (X, D) is sharply F -pure.

Remark 1.3. Since in characteristic 0 it is known that irreducible Θ divisors are normal with rational singularities, it is natural to wonder if over an algebraically closed field of characteristic p > 0, irreducible Θ divisors are normal with F -rational singularities. Note that a related result appears in [BBE07].

The characteristic 0 argument of Ein and Lazarsfeld relies on the theory of multiplier ideal sheaves, Kawamata-Viehweg vanishing and the Fourier-Mukai functor. In characteristic p > 0, the theory of Fourier-Mukai functors still applies and multiplier ideal sheaves can be replaced by test ideals. However, there is no good substitute for Kawamata-Viehweg vanishing (which is known to fail in this context). Instead, inspired by some ideas contained in [Schwede11], we use the "generic vanishing results" from [CH03], [Hacon04] and [PP08] 
to show that h 0 (X, σ(X, 1−ǫ m D) ⊗ O X (Θ) ⊗ Px) > 0 for a generalx ∈ X.
But then a general translate of Θ vanishes along the cosupport of σ(X, 1−ǫ m D). This is only possible if σ(X, 1−ǫ m D) = O X and so (X, 1−ǫ m D) is strongly F -regular and (1.1) follows. search grant DMS 0757897. preliminaries

Throughout this paper we work over an algebraically closed field k of characteristic p > 0. Recall that the ring homomorphism F : k → k defined by F (x) = x p endows k with a non-trivial k-module structure.


Test ideals.

Here we recall the definition of test ideals and some related results that will be needed in this paper. We refer the reader to [BST11] and [Schwede11] (and the references therein) for a more complete treatment. Let (X, ∆ = d i D i ) be a log pair so that X is a normal variety and ∆ ≥ 0 is a Q-divisor such that K X +∆ is Q-Cartier. Let F : X → X be the Frobenius morphism and for any integer e > 0, let F e be its e-th iterate. The parameter test submodule of (X, ∆) denoted by τ (ω X , ∆) is locally defined as the unique smallest non-zero
O X -submodule of ω X such that φ(F e * M) ⊂ M for any e > 0 and any φ ∈ Hom O X (F e * ω X (⌈(p e − 1)∆⌉), ω X ). The test ideal τ (X, ∆) is defined by τ (ω X , K X + ∆). It is known that τ (X, ∆) ⊂ O X is an ideal sheaf such that τ (X, ∆ + A) = τ (X, ∆) ⊗ O X (−A), and τ (X, ∆ + eA) = τ (X, ∆)
for any Cartier divisor A and any rational number 0 ≤ e ≪ 1. We also have that test ideals are contained in multiplier ideals in the sense that if π : Y → X is a proper birational morphism, then τ (X, ∆) ⊂ π * O Y (K Y − ⌊π * (K X + ∆)⌋). (Recall that in characteristic 0, if π is a log resolution, then the multiplier ideal is defined by J (X, ∆) = π * O Y (K Y − ⌊π * (K X + ∆)⌋).) In particular, if X is a smooth variety and mult x (∆) ≥ dim X, then τ (X, ∆) ⊂ m x where m x is the maximal ideal of x in X.

Suppose now that p does not divide the index of K X + ∆ so that (p e − 1)(K X + ∆) is Cartier for some integer e > 0. Let L e,∆ = O X ((1 − p e )(K X + ∆)). There is a canonically determined (up to unit) homomorphism of line bundles φ ∆ : F e * L e,∆ → O X . We have that τ (X, ∆) is the smallest non-zero ideal J ⊂ O X such that φ ∆ (F e * (J · L e,∆ )) = J. Similarly, we define σ(X, ∆) to be the largest ideal J ⊂ O X such that φ ∆ (F e * (J · L e,∆ )) = J. By definition (X, ∆) is strongly Fregular if τ (X, ∆) = O X , and sharply F -pure if σ(X, ∆) = O X . By [TW04, 2.2], we have that 1) if (X, ∆) is strongly F -regular then it is also sharply F -pure, and 2) if (X, ∆) is sharply F -pure and X is strongly F -regular, then (X, (1 − ǫ)∆) is strongly F -regular for any 0 < ǫ < 1.


Abelian varieties and the Fourier-Mukai transform.

Here we recall some facts about the Fourier-Mukai transform introduced in [Mukai81]. Let X be the dual abelian variety and P be the normalized Poincaré line bundle on X × X. We denote by RŜ : D(X) → D( X) the usual Fourier-Mukai functor given by RŜ(F ) = Rp X * (p * X F ⊗ P ). There is a corresponding functor RS : D( X) → D(X) such that
RS • RŜ = (−1 X ) * [−g]
and
RŜ • RS = (−1 X ) * [−g].
Let A be any ample line bundle on X, then R 0 S(A) = RS(A) is a vector bundle on X of rank h 0 (A) which we denote by A. For any x ∈ X, let t x : X → X be the translation by x and let φ A : X → X be the isogeny determined by
φ A (x) = t * x A − A, then φ * A ( A) = h 0 (A) A ∨ . If (X, Θ) is a PPAV, then φ Θ : (X, Θ) → ( X, Θ = φ Θ (Θ)) is an isomorphism of PPAVs. If A = O X (m Θ)
for some positive integer m > 0, then φ A : X → X can be identified with m X : X → X (multiplication by m) and so it has degree m 2 dim X and φ * A Θ ≡ m 2 Θ. (Note that the above notation is customary, but somewhat confusing as O X (− Θ) = R 0Ŝ (O X (Θ)).)

We will need the following result.

Proposition 2.1. Let F be a non-zero coherent sheaf on X such that H i (F ⊗ Px) = 0 for all i > 0 and allx ∈ X (where for anyx ∈X, we let Px = P | X×x ). If F → k(x) is a surjective morphism for some

x ∈ X, then the induced map
H 0 (F ⊗ Px) → H 0 (k(x) ⊗ Px) ∼ = k(x) is surjective for generalx ∈ X.
Proof. (Cf. [CH03, 2.3] or [PP08].) By cohomology and base change, one sees thatF = R 0 S(F ) = RS(F ) is a sheaf and since RŜ(F) = (−1 X ) * F [−g] = 0, we have thatF = 0. Let P x = P | x×X , then P x = R 0 S(k(x)) = RS(k(x)) and the homomorphism φ :F → P x is nonzero. However, as P x is a line bundle (and hence torsion free of rank 1), it follows that φ is generically surjective. The proposition now follows since for anyx ∈X, the corresponding fiber ofF (resp. RS 0 (k(x))) is
H 0 (F ⊗ Px) (resp. H 0 (k(x) ⊗ Px) = H 0 (k(x))).

main result

Proof of (1.1). Let 0 < ǫ < 1 be a rational number such that the index of ∆ = 1−ǫ m D is not divisible by p. We will show that (X, ∆) is sharply F -pure. Note that for any given m, we may find a sequence of ǫ i such that the index of ∆ = 1−ǫ i m D is not divisible by p and 0 = lim i→∞ ǫ i . Since X is regular, it follows by what we have observed in Subsection 2.1, that (X, (1 − ǫ)∆) is strongly F -regular for all rational numbers 0 < ǫ ≤ 1.

We now fix e > 0 such that (p e − 1)∆ is Cartier. For any n > 0 we have that φ n ∆ (F ne * (σ(X, ∆) · O X ((1 − p ne )(K X + ∆)))) = σ(X, ∆). We will show the following.

Claim 3.1. For any sufficiently big integer n ≫ 0, we have
H i (X, F ne * (σ(X, ∆) · O X ((1 − p ne )(K X + ∆))) ⊗ O X (Θ) ⊗ Px) = 0 for all i > 0 and allx ∈ X.
Granting the claim for the time being, we will now conclude the proof of the theorem. Let x ∈ X be a general point, so that in particular x is not contained in the co-support of σ(X, ∆). We have a surjection
F ne * (σ(X, ∆) · O X ((1 − p ne )(K X + ∆))) ⊗ O X (Θ) → k(x)
, which factors through σ(X, ∆) ⊗ O X (Θ) → k(x). By (2.1) and (3.1), we have that
H 0 (F ne * (σ(X, ∆) · O X ((1 − p ne )(K X + ∆))) ⊗ O X (Θ) ⊗ Px) → k(x)
is surjective for generalx ∈ X. Since this map factors through H 0 (σ(X, ∆)⊗ O X (Θ) ⊗ Px), we have that the induced homomorphism H 0 (σ(X, ∆) ⊗ O X (Θ)⊗Px) → k(x) is surjective. In particular H 0 (σ(X, ∆)⊗O X (Θ)⊗ Px) = 0, i.e. the corresponding translate of Θ vanishes along the co-support of σ(X, ∆). But then this co-support is empty so that σ(X, ∆) = O X .

Proof of Claim 3.1. It suffices to show that for all i > 0 we have H i (X, σ(X, ∆) · O X ((1 − p ne )(K X + ∆)) ⊗ F ne * (O X (Θ) ⊗ Px)) = 0.

By Serre vanishing (applied to the projective morphism p X : X × X → X and the coherent sheaf p * X (σ(X, ∆)·(F ne ×idX) * P ), we may fix t > 0 such that H i (X, σ(X, ∆) · F ne * Px ⊗ O X (tΘ)) = 0 for i > 0. By [PP03,2.9], it suffices to show that H i (X, O X ((1 − p ne )(K X + ∆) + (p ne − t)Θ)) = 0 for i > 0. By assumption (1 − p ne )(K X + ∆) + (p ne − t)Θ ∼ Q ((p ne − 1)ǫ + 1 − t)Θ. The claim now follows since (p ne − 1)ǫ + 1 − t > 0 for n ≫ 0.

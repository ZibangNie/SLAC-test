In this article, we show that every rational map whose multipliers all lie in a given number field is a power map, a Chebyshev map or a Lattès map.This strengthens a conjecture by Milnor concerning rational maps with integer multipliers, which was recently proved by Ji and Xie.Résumé (Fractions rationnelles avec multiplicateurs rationnels).-Dans cet article, nous montrons que toute fraction rationnelle dont les multiplicateurs sont tous dans un corps de nombres donné est une application puissance, une application de Tchebychev ou un exemple de Lattès.Ceci généralise une conjecture de Milnor concernant les fractions rationnelles avec multiplicateurs entiers, qui a été récemment démontrée par Ji et Xie.

Introduction

Suppose that f : C → C is a rational map.A point z 0 ∈ C is said to be periodic for f if there exists an integer p ⩾ 1 such that f •p (z 0 ) = z 0 .In this case, the least such integer p is called the period of z 0 and {f •n (z 0 ) : n ⩾ 0} is said to be a cycle for f .The multiplier of f at z 0 is the unique eigenvalue λ ∈ C of the differential of f •p at z 0 , so that λ = (f •p ) ′ (z 0 ) if z 0 ∈ C. The map f has the same multiplier at each point of the cycle.Furthermore, the multiplier is invariant under conjugation: if ϕ : C → C is a Möbius transformation and g = ϕ • f • ϕ −1 , then ϕ(z 0 ) is periodic for g with period p and multiplier λ.

The notion of multiplier is fundamental in complex dynamics and plays a major role in the study of both local and global dynamics of rational maps.Furthermore, multipliers almost determine rational maps up to conjugation: aside from flexible Lattès maps, there are only finitely many conjugacy classes of rational maps that have the same collection of multipliers at each period (see [McM87,Cor. 2


.3]).

The purpose of this article is to show that the multipliers of a rational map do not all lie in a given number field unless the rational map is exceptional.

Definition 1. -A rational map f : C → C of degree d ⩾ 2 is said to be a power map if it is conjugate to z → z ±d .

For every d ⩾ 2, there exists a unique polynomial
T d ∈ C[z] such that T d z + z −1 = z d + z −d .
The polynomial T d is monic of degree d and is called the dth Chebyshev polynomial.
Definition 2. -A rational map f : C → C of degree d ⩾ 2 is said to be a Chebyshev map if it is conjugate to ±T d .
Power maps and Chebyshev maps are exactly the finite quotients of affine maps on cylinders (see [Mil06,Lem. 3.8]).There are also finite quotients of affine maps on tori.

Definition 3. -A rational map f : C → C of degree d ⩾ 2 is said to be a Lattès map if there exist a torus T = C/Λ, with Λ a lattice in C, a holomorphic map L : T → T and a nonconstant holomorphic map p : T → C that make the following diagram commute:
T L / / p T p C f / / C Furthermore, if p has degree 2 and L is of the form L : z + Λ −→ az + b + Λ, with a ∈ Z, b ∈ C,
then f is said to be a flexible Lattès map.

Power maps, Chebyshev maps and Lattès maps play a special role in complex dynamics and are sometimes called exceptional.For example, their multipliers all lie in a discrete subring of C.

An imaginary quadratic field is a number field of the form Q(i √ D), with D a positive integer.Given a number field K, we denote by O K its ring of integers.

Proposition 4 ([Mil06, Cor.3.9 & Lem.5.6])

-Suppose that f : C → C is a power map or a Chebyshev map.Then f has only integer multipliers.

Here, we are interested in the converse of Proposition 4. We prove the following: Main Theorem.-Assume that K is a number field and f : C → C is a rational map of degree d ⩾ 2 whose multipliers all lie in K. Then f is a power map, a Chebyshev map or a Lattès map.

Main Theorem strengthens several recent results.These were motivated by a conjecture made by Milnor in [Mil06], which states that power maps, Chebyshev maps and flexible Lattès maps are the only rational maps that have only integer multipliers.This problem was first studied by the author in [Hug21], where the conjecture was proved for unicritical polynomial maps and cubic polynomial maps with symmetries.More generally, in light of Proposition 4, one could ask whether power maps, Chebyshev maps and Lattès maps are the only rational maps whose multipliers all lie in the ring of integers of a given imaginary quadratic field.In [Hug22], the author gave a positive answer to this question for quadratic rational maps.Finally, the general case was settled by Ji and Xie, who thus proved Milnor's conjecture.

Theorem 5 ([JX22, Th. 1.13]).-Assume that K is an imaginary quadratic field and f : C → C is a rational map of degree d ⩾ 2 whose multipliers all lie in O K .Then f is a power map, a Chebyshev map or a Lattès map.

In fact, the author proved in [Hug21] that every unicritical polynomial map that has only rational multipliers is either a power map or a Chebyshev map.Thus, one could even ask whether Theorem 5 still holds if K is an arbitrary number field and the multipliers of f are only assumed to lie in K. Main Theorem provides a positive answer to this question.

We note that Ji and Xie's proof of Theorem 5 makes crucial use of the fact that the multipliers all lie in a discrete subring of C, whereas the set of multipliers may a priori have limit points under the assumption of Main Theorem.Therefore, we take a different approach.Our proof of Main Theorem relies on an equidistribution result for points of small height proved by Autissier in [Aut01] and on a characterization of power maps, Chebyshev maps and Lattès maps proved by Zdunik in [Zdu14].

Finally, let us mention that Eremenko and van Strien investigated the rational maps that have only real multipliers in [EvS11].They proved that a rational map f : C → C of degree d ⩾ 2 has this property if and only if it is a flexible Lattès map or its Julia set J f is contained in a circle.

Proof of Main Theorem.-Assume that f : C → C is a rational map of degree d ⩾ 2 whose multipliers all lie in a given number field K.By [Sil98, Th. 2.1], the moduli space M d (C) of rational maps of degree d is an algebraic variety defined over Q. Denote by Z f the set of conjugacy classes [g] ∈ M d (C) such that f and g have the same multipliers with the same multiplicities at their cycles with period n for each n ⩾ 1.Then Z f is a Zariski closed subset of M d (C) defined over K by [Sil98,Th. 4.5].Moreover, it consists of finitely many elements of M d (C) and possibly a curve of conjugacy classes of flexible Lattès maps by [McM87,Cor. 2.3].Therefore, each rational map g : C → C of degree d such that [g] ∈ Z f is conjugate to a rational map defined over a finite extension of K or is a flexible Lattès map, and this holds in particular for f .If f is a flexible Lattès map, we are done.Thus, conjugating f and replacing K by a finite extension if necessary, we may assume that f is defined over K.

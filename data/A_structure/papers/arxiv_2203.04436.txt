We introduce and study a new class of morphisms which includes morphisms represented by monomorphisms in the sense of Auslander and Bridger.As an application, we give not only an extension of Kato's theorem on morphisms represented by monomorphisms, but also a common generalization of several results due to Auslander and Bridger that describe relationships between torsionfreeness and the grades of Ext modules.

Introduction

Throughout this paper, let R be a two-sided noetherian ring.We assume that all modules are finitely generated right ones.Denote by mod R the category of (finitely generated right) R-modules.It is a natural and classical question to ask when a given homomorphism of R-modules is stably equivalent to another homomorphism satisfying certain good properties.A well-studied one is about stable equivalence to a monomorphism: A homomorphism f : X → Y of R-modules is said to be represented by monomorphisms if there is an Rhomomorphism t : X → P with P projective such that f t : X → Y ⊕ P is a monomorphism.This notion has been introduced by Auslander and Bridger [1], and later studied in detail by Kato [9].Among other things, Kato gave the following characterization; we denote by Tr(−) the (Auslander) transpose.

Theorem 1.1 (Kato).Let f : X → Y be an R-homomorphism.Then the following are equivalent.

(1) The morphism f is represented by monomorphisms.

(2) The map Ext 1 R op (Tr f, R) : Ext 1 R op (Tr X, R) → Ext 1 R op (Tr Y, R) is injective.Motivated by the above theorem, we define a condition which we call (T n ) for each integer n 0 so that (T 1 ) is equivalent to being represented by monomorphisms, and find out several properties.The first main result is the following theorem, which recovers Theorem 1.1 as a special case.Theorem 1.2 (Theorems 3.6 and 3.9).Let n 1 be an integer.Consider the following conditions for an R-homomorphism f : X → Y .

The condition (T n )

We begin with introducing the new condition (T n ) for R-homomorphisms.It is a natural extension of the condition (2) in Theorem 1.1.Definition 3.1.Let n 1 be an integer.We say that a homomorphism f :
X → Y of R-modules satisfies (T n ) if the map Ext i R op (Tr f, R) is bijective for all 1 i n − 1 and Ext n R op (Tr f, R) is injective.
In addition, we provide that every R-homomorphism satisfies (T 0 ) and an R-homomorphism f satisfies (T ∞ ) if f satisfies (T n ) for all n 0.

In this section, we explore those homomorphisms which satisfy the condition (T n ).Below we give several statements which easily follow by definition.

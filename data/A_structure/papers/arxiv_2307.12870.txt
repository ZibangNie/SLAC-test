Introduction

The maximal operator for the Schrödinger equation on R n has been studied extensively. In particular, the pointwise convergence of solutions to the linear Schrödinger equation on R n has been established for initial data in Sobolev spaces with sharp range of exponents [DZ19].

For the Schrödinger equation on the one-dimensional torus, some partial results on the L p estimates of the maximal operators were obtained. [MV08] proved that sup 0<t<1 | N n=1 a n e(2π(nx + n 2 t))| L 6 ([0,1]) ≤ C ǫ N 1/3+ǫ ( N n=1 |a n | 2 ) 1/2 , which is sharp up to a C ǫ N ǫ factor. Some estimates for higher dimensional tori were obtained in [WZ19,CLS21].

It is conjectured that for every ǫ > 0, there exists a constant C ǫ > 0 such that
(1) sup t∈[0,N 2 ] N n=1 b n e x n N + t n 2 N 2 L 4 ([0,N ]) ≤ C ǫ N ǫ N 1 2 b n ℓ 2 ,
where b n are complex numbers. To recall, e(x) := e 2πix . It is shown in [Bar20] that (1) holds when b n = 1 for every n.

Similarly we could consider the maximal operator in the x direction, and it seems plausible to conjecture that for every ǫ > 0, there exists a constant C ǫ such that where b n are complex numbers. In this paper we describe some difficulties of this problem by showing both (1) and (2) cannot hold when we replace { n 2 N 2 } N n=1 by some uniformly convex sequences, whose definition we now give.
Definition 1.1. We say a sequence {a n } N n=1 (with parameter N ) is uniformly convex if it satisfies (3) a n+1 − a n ∈ 1 4N , 4 N (4) (a n+2 − a n+1 ) − (a n+1 − a n ) ∈ 1 4N 2 , 4 N 2 .
This definition coincides with the definition of generalized Dirichlet sequences in [FGM21]. We use the name of uniformly convex sequence in this paper in hope of better clarity in this context.

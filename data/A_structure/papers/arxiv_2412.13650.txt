Introduction

Let β(•, •) and Γ(•) denote the beta function and gamma function, respectively.For x, y ∈ R + , β(x, y) = Γ(x)Γ(y) Γ(x+y) .Let B = 1 β(i,j) = (i+j−1)!(i−1)!(j−1)!denote the beta matrix [14].We shall assume that 1 ≤ i, j ≤ n, unless otherwise stated.The matrix B is closely related to the Pascal matrix P = (i+j)!i!j! n−1 i,j=0

. For MATLAB toolbox for B, see [18].For numerical results and its usage in creating test matrices, see [7,9].See [23] for results on ratios of fractional series related to the gamma kernels.

One of the main objectives of this paper is to study some interesting properties of a related matrix [β(i, j)].This is the Hadamard or Schur inverse of B, generally denoted as B •(−1) .Studying properties of Hadamard inverses of some well known matrices has found usage in [4,17,27,28].

Let π(A), ξ(A) and ν(A), respectively, denote the number of positive, zero and negative eigenvalues of the matrix A. Then the triplet (π(A), ξ(A), ν(A)) is called the inertia of A and is denoted by Inertia(A).Finding inertia of matrices is an important problem in matrix theory, see [5,4,10,17,20,21].Our main result is the inertia of the matrix [β(i, j)].

Theorem 1.2.The n × n matrix [β(i, j)] is Birkhoff-James orthogonal to the matrix I in the trace norm if and only if n is even.

Similar results about the Hadamard inverse of the Pascal matrix are also pointed out.A matrix is called an integer matrix if all its entries are integers.The matrix P •(−1) is not an integer matrix, but it was proved in [28] that its inverse is.The Hilbert matrix given by H = 1 i + j − 1 is not an integer matrix but its inverse is an integer matrix, see [3].Likewise, there exist some other well-known non integer matrices, whose inverses are integer matrices, see [1,27,29].The next main result shows that the inverse of the matrix [β(i, j)] is also an integer matrix.To do so, we compute its entries explicitly.

3 Some properties of [β(λ i , µ j ) m ]
It is clear from Proposition 2.1 that [β(i, j)] is non singular.The below theorem gives a more general result.
Theorem 3.1. Let m ∈ N. Suppose 0 < λ 1 < • • • < λ n and 0 < µ 1 < • • • < µ n . Let µ i+1 − µ i ∈ N for all 1 ≤ i ≤ n − 1. Then 1 (Γ(λi+µj )) m and [β(λ i , µ j ) m ] are non singular.
To prove this result, we shall need the Descartes' rule of signs [26, p. 41, Ex. 36]: Let
p(x) = a p x p + a p−1 x p−1 + • • • + a 0(15)

Z(p(x)) ≤ N (p(x)). (16)
We now prove two lemmas.

Lemma 3.2.Let p(x) be a real polynomial of degree n given in (15).Let α > 0. Then we have

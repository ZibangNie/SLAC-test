德意志邦联成员邦国
德意志邦联的邦国于1815年6月20日加入这一组织，一直到1866年8月24日邦联解体期间的所有成员国的变化。总的来说，德意志邦联的范围基本与法国大革命爆发时神圣罗马帝国的领土一致，但比较明显的一部分就是排除了瑞士、比利时、荷兰、北意大利这些不再以德意志为民族认同的地区。邦联主要可以被分以下几部分：奥地利帝国、普鲁士王国、法国曾经占领的莱茵河西岸地区以及前莱茵邦联的全部成员国。
成员国
帝国
* 奥地利帝国，不包括匈牙利王国、特兰西瓦尼亚公国和克罗地亚-斯拉沃尼亚王国（所有这些都在多瑙河双君主制下成为匈牙利王国的一部分），伦巴第-威尼斯王国（1859割让给意大利）、布科维纳公国以及达尔马提亚和加利西亚王国。
* # 奥地利大公国（1849 年分裂为上奥地利和下奥地利）
* # 波西米亚王国
* # 摩拉维亚侯国
* # 萨尔茨堡大公国
* # 卡林西亚公国
* # 卡尼奥拉公国
* # 上下西里西亚公国
* # 施蒂里亚公国
* # 滨海区（由戈里齐亚和格拉迪斯、伊斯特拉和的里雅斯特组成）
* # 蒂罗尔
* # 福拉尔贝格
王国

* # 勃兰登堡
* # 波美拉尼亚
* # 莱茵省（直到1822年为下莱茵大公国和于利希-克莱沃-贝格省）
* # 萨克森
* # 西里西亚省
* # 威斯特伐利亚
* 巴伐利亚王国

* # 上弗兰肯
* # 施瓦本
* # 上普法尔茨
* # 中弗兰肯
* # 下巴伐利亚
* # 下弗兰肯
* # 普法尔茨
* 汉诺威王国（在1837年之前与英国联合）
* 萨克森王国
* 符腾堡王国
大公国
* 黑森选侯国（也称为黑森-卡塞尔）
* 巴登大公国
* 黑森大公国（也称为黑森-达姆施塔特）
* 卢森堡大公国（与荷兰联合王国合并；1839年荷兰联合王国解体时，其西部一半以上的领土被比利时夺走，从而导致林堡公国成为邦联成员国）
* 梅克伦堡-什未林大公国
* 梅克伦堡-施特雷利茨大公国
* 奥尔登堡大公国
* 萨克森-威玛-艾森纳赫大公国
公国
* 不伦瑞克公国（原不伦瑞克-沃尔芬比特尔公国）
* 荷尔斯泰因公国（与丹麦王国联合；不是莱茵联邦的前成员）
* # 石勒苏益格公国（丹麦的一个封地，与荷尔斯泰因公国同属丹麦王国，不是神圣罗马帝国或莱茵联盟的前成员。亲德分离主义者控制的石勒苏益格-荷尔斯泰因政府（1848-51）推动石勒苏益格加入德意志邦联，这并未得到邦联和丹麦政府的承认，1851年的协议明确规定石勒苏益格不是成员国）
* 林堡公国（于1839年成为与荷兰联合的成员国，以补偿因荷兰联合王国解体而造成的卢森堡大公国领土损失）
* 拿骚公国
* 萨克森-科堡-萨尔费尔德公国（1826年的萨克森-科堡和哥达）

* 萨克森-劳恩堡公国（与丹麦王国合并）

* 安哈尔特-贝恩堡公国（1863年与安哈尔特-德绍合并）

* 安哈尔特-克滕公国（1853年与哈尔特-德绍合并）

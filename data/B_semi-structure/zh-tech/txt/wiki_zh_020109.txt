中国横断自动车道（中国横断自动车道／ちゅうごくおうだんじどうしゃどう）是由姫路鸟取线、冈山米子线、尾道松江线、广岛滨田线构成的国土开发干线自动车道（国干道）路线名。略称为中国横断道（中国横断道／ちゅうごくおうだんどう）。
路线
按照国土开发干线自动车道建设法规定，中国横断自动车道如下。不过，市町村名为目前之名称。
除冈山米子线米子市附近 - 境港市以外的路段，根据高速自动车国道路线指定政令，高速自动车国道路线被指定如下。
姫路鸟取线
姫路鸟取线是在中国横断自动车道起点为姫路市、终点为鸟取市的路线。路线除经过中国地方也横跨近畿地方。通车路段的道路名为播磨自动车道与鸟取自动车道。部分路段与山阳自动车道、中国纵贯自动车道重复。
至2013年为止，以下的路段为目前已启用路段。
* 播磨系统交流道 - 播磨新宫交流道
* 佐用系统交流道 - 西粟仓交流道
* 智头交流道 - 鸟取交流道
另外，跨越冈山县与鸟取县县境间之西粟仓交流道 - 智头交流道间为高速自动车国道并行一般国道快速道路，以志户坂峠道路为名通车，补完鸟取自动车道。
冈山米子线
冈山米子线是在中国横断自动车道起点为冈山市、终点为境港市的路线。通车路段的道路名为冈山自动车道与米子自动车道。部分路段与中国纵贯自动车道重复。
至1997年为止，米子市 - 境港市除外区间已启用。
剩余路段之米子交流道 - 米子北交流道计划以新直辖方式建设。但是，未开工路段被选定为「彻底检讨路段」。
尾道松江线
尾道松江线是在中国横断自动车道起点为广岛县尾道市、终点为岛根县松江市的路线。通车路段的道路名为尾道自动车道与松江自动车道。部分路段与山阴自动车道重复。
建设促进期成同盟会公募其暱称为「中国山脉街道」（中国やまなみ街道）。
2015年全线启用。
广岛滨田线
广岛滨田线是在中国横断自动车道起点为广岛市、终点为滨田市的路线。通车路段的道路名为广岛自动车道与滨田自动车道。部分路段与中国纵贯自动车道、山阴自动车道重复。
1991年全线启用。
沿革
* 1965年（昭和40年）6月11日 : 中国横断自动车道建设法施行。预定路线2路线相关法律案的基准公告。
 * 冈山市 - 冈山县真庭郡落合町附近 - 境港市
 * 广岛市 - 滨田市
* 1966年（昭和41年）7月1日 : 以中国横断自动车道名义成为国干道预定路线。
 * 冈山米子线 : 冈山市 - 冈山县真庭郡落合町附近 - 米子市附近 - 境港市
 * 广岛滨田线 : 广岛市 - 滨田市
* 1974年（昭和49年）12月21日 : 冈山米子线落合交流道 - 落合系统交流道预定地（中国纵贯道重复区间）通车，为最先启用路段。
* 1983年（昭和58年）3月24日 : 广岛滨田线广岛北交流道 - 广岛北系统交流道 - 千代田系统交流道预定地（中国纵贯道重复区间）通车，为最先启用路段。
* 1987年（昭和62年）6月30日 : 第四次全国总合开发计划阁议决定。构想出高规格干线道路。
 * 姫路・鸟取自动车道 : 姫路市 - 鸟取市
 * 阴阳联络自动车道 : 尾道市 - 松江市
* 1987年9月1日 : 四全总受国干道法修正，预定路线变更如下。
 * 姫路鸟取线 : 姫路市 - 兵库县佐用郡佐用町附近 - 鸟取市
 * 冈山米子线 : 冈山市 - 冈山县真庭郡落合町附近 - 米子市附近 - 境港市
 * 尾道松江线 : 尾道市 - 三次市附近 - 松江市
 * 广岛滨田线 : 广岛市 - 广岛县山县郡千代田町附近 - 滨田市
* 1991年（平成3年）12月7日 : 广岛滨田线千代田系统交流道 - 旭交流道通车，全线启用。
* 1995年（平成7年）11月30日 : 道路审议会答申后，公告以并行一般国道快速道代替。
 * 姫路鸟取线 : 志户坂峠道路
* 2001年（平成13年）3月24日 : 尾道松江线 宍道交流道 - 松江玉造交流道（与山阴道重复区间）通车，为该路线最早启用路段。
* 2003年（平成15年）3月29日 : 姫路鸟取线 播磨系统交流道 - 播磨新宫交流道（与山阳道重复区间）通车，为该路线最早启用路段。
* 2003年12月25日 : 国干会议 选定新直辖区间。
 * 姫路鸟取线 : 佐用町 - 西粟仓村、智头町 - 鸟取市
 * 冈山米子线 : 米子市 - 米子市
 * 尾道松江线 : 尾道市 - 三次市、三次市 - 三刀屋町
* 2004年（平成16年）1月30日 : 尾道松江线在国干会议时受到道路公团将已发出的施行命令（尾道系统交流道 - 三刀屋木次交流道）撤回。
* 2006年（平成18年）2月7日 : 国干会议 选定「彻底检讨区间」。
 * 冈山米子线 : 米子市 - 米子市
* 2009年（平成21年）3月14日 : 姫路鸟取线 智头交流道 - 河原交流道通车，以新直辖区间方式成为该路线最早启用路段。
* 2010年（平成22年）11月27日 : 尾道松江线 尾道系统交流道 - 世罗交流道通车，以新直辖区间方式成为该路线最早启用路段。
* 2015年（平成27年）3月22日 : 尾道松江线 世罗交流道 - 吉舍交流道通车，该路线全线启用。
